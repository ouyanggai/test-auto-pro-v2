## 功能清单

### 一、测试计划

- 计划列表：按名称、状态筛选；展示流程、发起账号、路径数量、运行方式、定时信息、计划状态、最近运行结果；默认按最近修改倒序。
- 计划状态：未运行 / 运行中 / 已运行，由运行事实决定，不回退。
- 新建计划：填写名称与真实账号并验证；新建只开放“新发起”（选择当前账号可见的流程模板）；选择串行或并行（并行可设最大并发数）；可选单次定时启动。
- 编辑计划、编辑路径、运行入口对所有状态开放；旧来源（已发、待发）计划仍可按原值编辑。
- 创建失败保留输入可重试；重复提交只得到同一条计划。

### 二、执行路径与配置

- 读取真实流程结构，以流程图（Vue Flow）显示真实流程树，选择并保存执行路径（只保存真实分支选择）。
- 路径要求分析：条件、人员和节点要求，路径状态展示配置完成度。
- 路径配置工作区：按节点配置人员（范围内选人）、表单与字段权限、分段填写。
- 历史业务数据回放：按目标接口原字段选择历史实例并深复制表单数据，支持 FormMaking 与自定义表单（NoFormFlow）；配置期缺失必填项安全补齐，支持文件上传。
- 动作编排：同一主实例上的有序动作（保存草稿、审批暂存、同意、转发、加签、取回等），支持拖拽排序、状态感知的动作循环、动作执行流程预览与一键配置。
- 转发：主请求 → 新实例附言两步执行，失败即停、防重发。
- 加签人员排除名单：停用账号自动过滤，并可手动维护名单。

### 三、运行与任务中心

- 运行前检查：按路径列出阻塞与提醒，只运行就绪子集。
- 运行模式与调试：模式、断点与控制。
- 执行：使用目标平台真实账号、实例和接口；一次写约束、账号串行、会话缓存、读写差异化重试。
- 多路径调度：串行 / 并行，单次定时启动；单条路径失败不影响其他路径。
- 结果：成功 / 失败 / 已停止 / 已取消 / 结果待确认；写结果无法确认时明确终局，不自动重放。
- 失败动作重试：确定失败的动作可从失败步骤由用户显式重试。
- 任务中心：等待中、运行中和历史任务统一查看。
- 运行画布：以当前步为中心，事件流看整条流程，动作详情只看当前动作的接口、原始错误与真实耗时。
- 分层日志与追踪：追踪号与日志复制，缺失证据时明确说明。

### 四、报告中心

- 基于真实运行记录的“总分总”度量：计划总览 → 路径 → 运行实例，逐级下钻。
- 指标：路径运行成功率、一次通过率（FPY）、路径覆盖度、目标接口调用（读/写）、重试、步骤与接口耗时、结果与失败分类分布等。
- 名词解释随手可查，比率带分子分母，数据口径写明。

### 五、系统设置

- 常用账号、排除账号、排除流程（均从目标平台真实候选中选择）。
- 表单运行时维护：固定来源的“一键同步并更新运行时”，失败自动回退。
- 加签人员排除名单（见上）。

### 六、外观

- 顶栏深色 / 浅色切换。
- 三套未来感皮肤与全界面打磨：规划中（F-049，待批准实施），见 `docs/features/F-049-visual-spec.md`。

### 七、部署与运维

- Docker Compose 六服务发布（MySQL、后端、前端、配置表单、独立执行服务、日志查看器）。
- Windows 一键更新入口 `deploy/update.cmd`，构建与健康失败门禁、并发锁。
- 目标语义一致性套件（受控写默认关闭）。
