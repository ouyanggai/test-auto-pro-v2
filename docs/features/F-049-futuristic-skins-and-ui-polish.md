## 做完以后是什么样

保留现在的风格，名称叫“默认”，保留当前配色，同时把排版、留白、边框、弹窗和信息层次认真整理一遍。再增加“深空指挥舱”“极光玻璃”“钛金精密”三套差异明显的未来感皮肤。

四套皮肤各有浅色和深色，共八种外观组合。用户在顶栏切换后立刻看到效果，刷新仍保留自己的选择。变化覆盖整个工具界面，包括弹窗、下拉、画布和报告图表。

最重要的约束是：换了外观，手里的工作照常进行。正在填写的内容、打开的弹窗、画布位置和当前选择都要保留，流程执行、请求与错误信息不能受到影响。

## 这次具体打磨哪里

### 外观入口

- 顶栏增加“外观”入口，用四张缩略卡选择皮肤，同时提供独立的深浅色切换。
- 点击立即生效；未选择新皮肤时使用“默认”，沿用当前浏览器的深浅设置。
- 当前皮肤和深浅选择在刷新后保持，不增加账号设置、后端接口或数据库配置。

### 页面与所有常用元素

- 覆盖计划列表、新建与编辑、路径选择与配置、运行记录与运行详情、报告中心、系统设置。
- 按钮、输入框、选择器、表格、分页、页签、标签、提示、加载、空态、滚动条、流程图和图表都跟随外观，页面内部不再各有一套颜色。
- 间距统一使用 4、8、12、16、24、32、48px；普通页面水平留白随桌面宽度在 24—48px 之间调整。
- 标题、正文、辅助说明、数字和操作区有清楚的主次。列表方便快速扫读，配置页分组清楚，运行详情继续以画布为主。
- 保留当前导航、业务字段和操作入口。状态颜色必须表达真实的成功、失败、警告、等待或运行，不能被皮肤装饰色冲淡或替代。
- 报告图表的文字、坐标、图例和悬浮提示一起换肤，指标内容和统计口径保持原样。

### 动效

- 三套新皮肤各自有持续背景氛围，以及卡片、按钮、页签、弹窗的光感反馈。
- 装饰层独立于业务内容，不接收点击、不遮住文字、不挪动实际操作位置。
- 动效使用 CSS 合成动画；指针跟随统一由一个回调处理。具体实现边界以架构文档为准。
- 流程中的运行、成功、错误反馈由真实状态驱动；装饰动画不充当任务进度。

## 不能破坏的功能

1. 切换外观只更新视觉配置，不重建路由页面、表单 iframe、流程图或图表。
2. 保留未保存的输入、路径草稿、画布平移与缩放、选中节点、图表图例选择和已打开的弹窗。
3. 原生业务表单内部不注入工具皮肤，不修改其白底、字段样式、校验、数据回填或保存行为。
4. 不改业务请求、执行顺序、重试、安全核验、保存逻辑或运行判定；切换外观不额外调用业务接口。
5. 目标平台错误原话、接口流转与耗时保持完整。错误再长也不能为了整齐而截断、改写或藏掉；只整理已有内容和入口，保持当前原始日志正文的访问边界。
6. 画布不因为换肤重新适配视口。节点的尺寸、端口、连线和命中区要继续对齐。
7. 原有 loading、禁用、确认和关闭门禁继续有效，装饰图层不能拦截它们。

本切片只处理工具前端外观。不调整目标平台源码、执行器、后端、数据库、接口协议或业务规则，不增加手机端应用或新的 UI 框架。
