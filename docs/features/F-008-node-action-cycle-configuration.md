## 目标

测试人员可以用少量明确操作完成很多节点、很多路径的准备：为单节点配置动作与次数，按目标流程引擎的真实规则建立循环，选择本次要测试的路径，并随时单独修改任何路径、节点或循环。

## 状态机

```
草稿
  -> 校验通过
  -> 节点动作
  -> 不同意: 驳回到发起人 -> 重提后重新解析路径
     或回退: 返回上一个待办
  -> 重新核对下一次到达或完成
```

- 重新发起一整轮必须从发起提交开始，成员为当前路径连续的业务节点，且最后一个节点能不同意；重提后条件、并行和人员均按目标实例重新解析。
- 上一节点返工没有用户可选的回退目标：服务端只接受当前待办的真实前驱，并自动展示该两节点回路；前驱是发起节点时必须改用不同意，不得保存回退循环。
- 暂存、加签、移交和转办不进入静态循环；同一动作次数大于一时，校验器必须在上述状态机中找到每次重新到达该节点的真实回路，不能把次数转换成连续目标写请求。
- 循环次数和动作次数相乘后的计划执行量继续受既有单节点和路径总量上限限制。

## 用户交互

- 右侧节点面板只显示准备情况、已配置摘要和两个入口；不内嵌旧的到达、步骤、前置动作、组合次数或兼容字段。
- “动作配置”标题为当前节点名称。每行依次是动作、次数和这个动作必需的人员参数；默认次数为 1，唯一合法的动作或人员策略自动带入。用户只会看到当前可用动作，没有可用动作时直接说明当前无需配置。
- 每一行表示该节点被真实再次到达时的动作顺序，不是一次点击连发多个目标操作。一个会结束或推进待办的动作后不能继续追加另一个结果；保存时若次数无法由重提整轮或上一节点返工支撑，直接说明需要先建立哪一种循环。
- “循环配置”只提供引擎实际支持的两种选项。重提整轮从发起提交开始选择可不同意的结束节点，系统自动展示本轮节点和动作；上一节点返工自动展示上一个待办与当前待办，用户不能指定回退目标。
- 节点配置页顶部只显示当前路径准备进度；右侧可保存当前节点或顺序保存全部已满足规则的节点。运行路径选择回到计划详情的路径列表，每条路径可单独勾选，并提供全选和取消全选；选择不启动运行，后续运行只允许已准备路径进入。
- “一键预设”先选当前路径、已选路径或全部兼容路径，再展示一页预览：为每个节点预设一个随机动作，并尽量覆盖不同动作；已有人工动作会保留，需要人工补充人员的节点会单独列出。不自动建循环，不覆盖人工确认的配置。
- 保存失败定位到动作、循环或路径项并保留输入。普通保存不二次确认；删除、放弃未保存输入和覆盖人工配置才确认。所有文案使用业务语言，不暴露技术状态或内部标识。

## 后续执行大纲

F-008 仅完成工具侧配置。后续运行切片必须在每个目标动作前读取当前实例、待办、权限、批次和节点快照；一个状态迁移只调用一个目标接口，响应不确定时先查询真实实例与待办再决定是否重试。不同意后确认实例已为 `rejected` 才重提；回退后以新的批次和待办为事实继续。

## 人工验收

1. 打开一条已保存路径的节点配置画布，选择审批节点，确认右侧只显示“动作配置”入口，循环入口暂时隐藏，人员和表单区域未被混入。
2. 在“动作配置”中按节点添加、排序、删除动作并填写次数、人员或回退前驱条件，保存后重新打开确认只影响当前节点。
3. 在“循环配置”中建立从发起提交到不同意的多节点重提循环；确认页面说明重提后会重新核对路径。选择上一节点返工时，确认页面只展示系统识别到的上一个待办，不能自选任意节点。
4. 对多条路径使用一键预设，确认预览准确列出填入、保留、跳过与待处理项目，不创建循环、不覆盖人工配置；在结构完全一致的路径间复制已保存循环，确认不兼容路径不能选择。
5. 勾选、取消勾选本次要测试的路径，确认准备情况同步显示已选、已准备和缺项数量，未完整准备的路径不能在后续运行阶段被静默执行。
6. 尝试跨分支拼接循环、跳过中间节点、在发起节点后回退、将暂存/加签/移交加入静态循环，确认系统阻止并保留已输入内容。
7. 刷新后确认循环、节点动作和本次测试路径选择仍以新的独立结构恢复；旧动作记录不会被读取，也不会显示到达、步骤或伪造的循环。
