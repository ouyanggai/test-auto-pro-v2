# F-008 节点动作与循环配置

- 状态：awaiting_approval
- 产品依据：`docs/PRODUCT.md` 的“节点动作与循环配置行为（F-008）”
- 架构依据：`docs/ARCHITECTURE.md` 的“F-008 节点动作与循环配置”
- 计划确认时间：2026-08-17

## 目标

测试人员可以在一条已保存执行路径的节点画布内，分别配置某个节点的动作与次数，并把多个连续节点的已配置动作组合成一个具有真实返回语义的循环；循环只能按“不同意后重新发起”或“回退到循环起点”闭合。

## 范围

- 包含：
  - 右侧节点面板的独立“动作配置”和“循环配置”入口与两个模态工作区。
  - 节点侧栏的简短已配置摘要；动作列表编辑，以及“起点/终点 -> 自动成员摘要 -> 返回方式与次数”的循环配置交互。
  - 面向非技术测试人员的默认值、渐进展示、就近中文反馈和不丢失输入的错误处理。
  - 发起、审批和协同节点的 V1 已验证动作目录、动作参数与动作次数配置。
  - 在同一已保存路径中选择连续的一个或多个已配置动作节点，创建、编辑、删除和读取循环配置。
  - 两种循环返回方式、循环次数与动作次数的独立展示、服务端状态机校验、旧动作 JSON 的一次性迁移和待配置投影。
  - 当前范围的后端单元/契约、前端单元与结构验证，全部存放在根目录 `test/` 对应分类。
- 不包含：
  - F-005 路径选择、分支编辑、流程图布局或人员配置改造。
  - FormMaking 表单运行时、字段生成、字段保护和目标写入边界改造。
  - 目标平台实际提交、审批、不同意、回退、加签、移交，或运行记录/调度执行。
  - 任意节点跳转、按名称猜测回退目标、跨分支拼接循环、网络重试模拟或新数据库迁移。

## 状态机

```
草稿
  -> 校验通过
  -> 从循环起点依路径顺序执行成员节点动作
  -> 循环终点执行返回动作
  -> 不同意: 发起人重新提交 / 回退: 精确回到循环起点
  -> 回到起点（下一轮）或完成
```

- 成员节点必须是当前路径上连续的可配置业务节点，且每个成员已有合法动作配置。
- 不同意方式必须由循环终点的真实动作目录允许；返回后必须经过发起人提交才能重进起点。
- 回退方式必须由循环终点的真实动作目录允许，且服务端给出的唯一回退目标与循环起点完全一致。
- 同一动作次数大于一时，校验器必须在状态机中找到每次重新到达该节点的真实回路；不能把次数转换成连续目标写请求。
- 循环次数和动作次数相乘后的计划执行量继续受既有单节点和路径总量上限限制。

## 完成标准

- [ ] 节点面板不再同时渲染旧的到达、步骤、加签/处理结果和组合循环编辑器；动作配置与循环配置分别通过明确按钮打开。
- [ ] 节点侧栏只显示必要摘要和两个入口；动作配置不离开当前节点，循环配置不要求手工拼接或重排节点成员。
- [ ] 动作弹窗每行只展示动作、次数及必需参数；循环弹窗固定按起点/终点、自动动作摘要、返回方式/循环次数三段收敛，错误准确定位且保存失败保留草稿。
- [ ] 用户不需要理解状态机、拓扑、技术键或旧配置：界面使用“从哪里开始”“到哪里结束”“怎么回到起点”等中文，次数默认 1，唯一合法选择自动带入。
- [ ] 循环配置先选起点，再只提供可到达终点，最后以完整中文句子展示将执行的节点和返回结果；普通保存不二次确认，删除或放弃未保存输入才确认。
- [ ] 动作配置仅保存当前节点；可用动作、次数、人员和回退参数均由当前目标快照校验。
- [ ] 循环配置能清楚展示起点、成员节点、终点、动作摘要、返回方式和循环次数；动作未配置、跨分支、非连续或返回不可证明时不能保存并说明原因。
- [ ] 不同意回路必须表现为“终点不同意 -> 发起人 -> 重新提交 -> 循环起点”；回退回路必须精确落到循环起点。
- [ ] 旧动作记录不会与新 DTO 或界面混合；不能无损迁移的旧组合显示为待配置，绝不自动生成循环。
- [ ] 代码已实际执行；相关测试、类型检查或构建已通过；同一动作契约、循环校验与旧值读取范围已检查。
- [ ] 文档状态更新为 `ready_for_manual`，并停止在人工验收门禁。

## 人工验收

1. 打开一条已保存路径的节点配置画布，选择审批节点，确认右侧只通过“动作配置”和“循环配置”进入对应工作区，人员和表单区域未被混入。
2. 在“动作配置”中按节点添加、排序、删除动作并填写次数、人员或回退参数，保存后重新打开确认只影响当前节点。
3. 在“循环配置”中选择连续的多个已配置节点，确认能阅读完整动作摘要；分别保存“不同意后重新发起”和“回退到循环起点”的合法配置。
4. 尝试跨越未选分支、跳过中间节点、包含未配置动作、将回退指向非循环起点或让单节点动作次数无真实回路，确认系统阻止保存且保留当前输入。
5. 刷新后确认循环和节点动作仍以新的独立结构恢复；旧动作记录不会显示到达、步骤或伪造的循环。
6. 让未接触过当前页面的测试人员完成一次动作与循环配置，确认无需阅读技术说明即可知道下一步；遇到缺少动作或不能回到起点时，提示直接说明应补什么而不丢失已输入内容。
