## 目标

测试人员勾选多条已保存路径后，可以启动独立后台准备任务。任务在同一真实流程快照下补齐尚未人工保存的节点默认配置，并为每条路径确定性生成能命中完整线路的表单数据；人工配置始终保留，不能安全求解的路径明确进入“数据需处理”。

## 状态语义

- `configurationStatus` 只由节点人员与动作配置决定：`pending`、`partial`、`configured`、`affected`。表单是否生成不得改变节点配置状态。
- `dataStatus` 只表示表单数据准备：`not_required`、`not_generated`、`generated`、`confirmed`、`needs_attention`。
- 人工在真实 FormMaking 页面保存后为 `confirmed`；服务端安全生成并复验后为 `generated`；条件不可解、未知组件/比较能力或人工值与当前路径冲突为 `needs_attention`。
- 后续运行预检只允许节点配置完成且数据无需准备、已生成或已确认的路径进入运行；F-009 只记录规则，不实现真实运行。

## 后台任务

- 新增独立批量准备任务表和任务明细表，不复用全路径解析任务。
- 创建任务只读取当前计划已经勾选的路径；同计划最多一个活动任务，幂等键重复提交返回同一任务。
- 任务提供总数、已处理、节点已配置、数据已生成、需处理、失败和保留人工配置数量；明细按游标分页返回单路径状态及中文原因。
- 任务在领取和完成明细时记录当前处理路径的 ID、稳定序号、名称和明细状态；详情接口返回该轻量字段，页面不通过逐条明细请求或客户端动画推导当前进度。
- 支持取消与恢复，从未完成明细继续；单条失败不回滚其他路径。
- 每次任务只读取一次真实流程快照、表单模板、身份目录和有限近期样本；路径及配置分批读取和保存，禁止目标平台逐路径 N+1 与无界内存累积。
- 已保存节点配置和人工确认表单永不覆盖；人工数据与路径冲突时保留原值，只标记为需处理。

## 确定性求解

- 生成值必须让当前选中分支成立，并让同一路由节点中排序更靠前的全部分支不成立；兜底分支必须避开所有前置分支。
- 按目标 `sort` 和实际 `and/or` 顺序复验完整路径，支持 `eq`、`neq`、`gt`、`gte`、`lt`、`lte`、`contains`、`in`、字段对字段、日期及日期范围。
- 数值从条件边界构造，选项只使用模板真实候选，身份组件只使用当前账号真实公司、部门和人员。
- 未知字段、比较方式、动态脚本和复杂组件不猜测，返回安全部分数据与中文问题。
- 相同模板、路径和 seed 生成稳定；“换一组”只能在仍命中完整路径的候选中变化。

## API 与页面

- 单条生成返回 `generationState: complete|partial|blocked`、`issues` 和 `routeVerification`。预期求解失败使用 2xx 返回安全部分数据；保存仍做服务端权威复验。
- 计划详情分别展示节点配置状态和数据准备状态，并支持“数据需处理”快速筛选。
- “一键配置”只对勾选路径创建后台任务；页面显示真实进度，刷新可恢复活动任务，完成后刷新路径列表，不跳进单条配置页。
- 页面只保留一块进度区，显示已处理/总数、当前处理路径和真实聚合计数。任务完成时先刷新路径双状态，成功后自动收起；取消或失败保留简短结果和恢复按钮。
- 勾选集合允许包含未配置节点的路径；发现此类路径时使用虚拟列表 `scrollTo({ index })` 定位第一条，约三秒高亮并提示“已选择未配置路径，请先配置节点”，不阻止一键配置。
- 页面支持取消、恢复和分页明细；每条失败只显示中文原因，不展示技术错误长串。
- 行内继续保留“配置节点”；已生成数据进入 FormMaking 页面后直接回显并允许人工微调，关键条件字段继续锁定。
- 删除旧同步一键预设公开入口，不保留兼容 API。

## 计划公开状态与路径准入

- `test_plans.status` 只保留 `not_started`（未运行）、`running`（运行中）和 `completed`（已完成）；新建计划为 `not_started`，014 号开发迁移把旧开发值一次性收敛为 `not_started`。
- 路径编辑、节点配置、表单配置和批量准备仅允许未运行计划；运行中和已完成计划只读。计划详情不再显示“待配置/可运行”计划标签，配置完成度由路径的 `configurationStatus` 与 `dataStatus` 汇总表达。
- 未来运行资格集中判定：`configurationStatus=configured`，`dataStatus` 为 `not_required`、`generated` 或 `confirmed`，并且没有 `needs_attention`。本切片只提供后端/前端规则和未配置定位，不实现真实运行接口。

## 人工检查点

1. 勾选多条路径后点击“一键配置”，确认刷新页面仍能看到同一任务及真实进度，任务不会进入单条页面。
2. 取消并恢复任务，确认只继续未完成路径；单条需处理不影响其他路径完成。
3. 分别核对节点配置与数据状态；表单未生成时已配节点仍保持“已配置”。
4. 打开已生成路径的表单页面，确认生成值回显、关键条件字段锁定，人工保存后数据状态改为“已确认”。
5. 核对请假流程兜底路径自动生成的请假天数不会命中更靠前审批分支，且日期区间与天数一致。
