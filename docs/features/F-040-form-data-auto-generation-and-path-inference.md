# F-040 表单数据自主生成、智能历史检索与已发路径推导

- 状态：ready_for_manual
- 产品依据：`docs/PRODUCT.md` 路径选择、历史业务数据回放与节点动作编排
- 架构依据：`docs/ARCHITECTURE.md` 表单运行时、路径数据工作区与目标只读适配器
- 计划确认时间：2026-09-23

## 目标

解决表单数据强制依赖历史实例、已发实例表单数据未自动继承、合同组件名称不回显与版本滞后、历史实例查询硬编码过滤导致查不出，以及已发流程无法自动推导后续路径的核心阻断问题。

## 范围

- 包含：
  1. 合同自定义组件回显修复（兼顾 `contractName`、`name` 以及纯 ID 反查）与 `contract-change-list-select` 组件注册与源码启动拉取配置；
  2. 已发/待发流程自动继承已绑定实例的真实表单数据作为初始基线，免除弹窗二次选择；
  3. 新发起流程放开 `source.snapshot` 强制门禁，允许直接在目标表单组件内填写并保存作为完整表单数据；
  4. 历史实例查询彻底移除 `flowInstanceBizRelevanceList`、`useScope: "invest"` 硬编码过滤，支持跨账号与全状态智能检索；
  5. 已发/待发流程从当前节点自动推导后续确定分支路径；遇未填条件字段或手动分支时给出明确完善提示。
- 不包含：
  - 目标平台写接口规则变更；
  - 自动执行写动作。

## 完成标准

- [x] 合同组件正确解析并回显合同名称，`contract-change-list-select` 正常挂载。
- [x] 已发/待发计划在数据工作区直接继承该实例当前表单数据，保存无需选基础数据。
- [x] 新发起计划在未选基础数据时，支持直接从表单组件捕获 values 并成功保存。
- [x] 历史实例列表能查出机房进入申请表等无公司关联或非投资类的业务实例。
- [x] 已发流程在进入路径页面时，自动推导生成后续无歧义分支路径。
- [x] 全部定向单测、Go 构建、vet 与前端类型检查通过。
- [x] 文档状态更新为 `ready_for_manual`。

## 人工验收

1. 点开含合同组件的表单数据，核验合同名称是否正确回显；
2. 新建已发流程计划，进入路径配置与表单数据，核验是否直接展示该实例已有数据且直接保存成功，不再提示“请先选择基础表单数据”；
3. 新建新发起流程计划，不选基础数据直接在表单填写数据并保存，核验是否成功保存；
4. 搜索“机房进入申请表”，核验历史实例列表中是否能查到历史流程数据；
5. 选择已发流程，核验是否自动推导出后续执行路径。
