## 单一用户结果

用户为计划保存执行路径后，可以选择任一路径，按当前目标平台真实配置核对这条路径为了后续自动执行还需要准备哪些条件数据、处理人和节点动作，并能区分哪些由目标平台自动确定、哪些只能在运行时确定、哪些规则当前无法可靠识别。

F-006 只回答“后续要准备什么、由谁决定”。它不填写表单值、不选择人员、不保存动作、不调用目标写接口，也不把计划变为可运行。

## 实施结果

- 新增 `GET /api/plans/{planId}/execution-paths/{pathId}/requirements`。服务先在计划范围内确认路径归属，再使用计划保存的账号、来源和目标对象读取当前真实配置；保存选择无法完整对应当前图时返回 `EXECUTION_PATH_INVALID`。
- 目标读取沿用 F-004/F-005 同一棵结构树。节点内部补充解码 `conditionList`、`flowNodeAuditConfig`、`flowNodeFieldPowerTemplateList`、`isSkip`、`delay`、`unit`、`deadlineType`；新发起从 `formTemplateList` 读取 `/web/formTemplateApi/findById`，已发/待发从精确实例记录的 `formProxyId` 读取 `/web/formProxy/findById`，字段字典只取 `fieldsTemplateList` 的名称关联。
- 独立分析器复用当前图与执行路径可达结果，生成主线和并行分组。条件比较、`and/or`、字段对常量/字段、最后分支兜底、手动分支、并行必经、人员类型、会签/竞签、人数、范围、`isSkip`、动作和运行态限制均转换为中文；未知字段、枚举、范围或人数只降级对应单项。
- 公开响应只包含路径稳定序号和名称、四类中文汇总、业务节点名称/类型及中文要求项；不包含路径选择 ID、目标节点/分支 ID、字段英文名、目标枚举、SID、目标原文或表单 JSON。
- 新增 `/plans/:id/requirements` 只读页面。路径选择页的页面级标题区在已有路径时显示“核对路径要求”；核对页左侧选择已保存路径，右侧按主线/并行展示，旧请求会取消，并以路径标识和版本双重阻止迟到响应覆盖。
- 没有关联代理表单或字段无法唯一匹配时，页面显示“未识别的表单字段”并标为“需要人工核对”，不回退模板字段或猜测内部名称。
- 自动验证已实际运行 `./test/run-f006.sh`，覆盖 F-006 后端单元、API 契约、三类假目标和表单详情、会话整链重放、超时、取消、8 MiB 响应上限、前端切换与结构、F-004/F-005 必要回归、Go build、`vue-tsc`、Vite build 和 `git diff --check`；未启动浏览器。

## 真实行为依据

- 目标模板和代理详情的 `flowNodeTemplate` 同时包含 `conditionNodes`、`parallelNodes`、节点审批配置和字段权限；当前工具只提取了结构，F-006 可以在同一次详情解码中补充内部要求元数据，无需再建立一棵流程图。
- 目标条件包含字段 A、字段 B 或固定值、判断方式和 `and/or` 连接关系。目标执行服务按分支顺序判断，并在前序条件均不成立时无条件选择最后一个分支，因此最后分支必须按兜底表达，不能只看它是否携带条件列表。
- 目标审批配置支持指定人员、角色、公司、部门、岗位、职级、发起人、部门主管、分管副总、扩展属性、表单人员和审批人自选，并包含会签/竞签、人数、配置明细、范围和无处理人跳过规则。
- `GroupApproveManage/CheckFlow` 按上述规则展示人员配置；待办页面把审批/协同作为主要处理入口，同时提供回退上一级、向当前节点添加审批人和转发等依赖真实任务状态的操作。这些特殊操作不能仅凭静态树判定当前一定可用。
- 表单模板详情和表单代理详情都能返回字段元数据；字段英文名只适合作为目标内部关联键，产品页面必须使用字段名称，并对无法消歧的引用明确提示人工核对。

## 包含范围

### 页面入口与布局

- 在计划路径配置页的页面级操作区增加“核对路径要求”，不占用 F-005 画布右上角工具栏，也不改变“路径入口只在页面全屏显示”的既有规则。
- 新增 `/plans/:id/requirements` 整页路由，左上角固定返回路径选择；页面主体左侧显示已保存路径序号和名称，右侧显示当前路径要求。
- 默认选择稳定序号最小的路径；用户切换路径时取消旧请求或忽略迟到响应，不能让旧路径内容覆盖当前选择。
- 右侧顶部显示四类状态数量；主体按主线和并行分组展示节点。并行分支各自成组，汇合后的公共节点只显示一次。
- 页面只读，不放置名称输入、人员选择、动作选择、保存、运行或伪禁用的“下一步”按钮。

### 条件要求

- 只显示当前路径已选条件分支；未选分支不进入要求清单。
- 保留条件在目标中的顺序和 `and/or` 连接语义，比较方式转换为中文；固定业务值允许显示，字段英文名和判断枚举代码不显示。
- 字段引用通过关联表单字段元数据转换为名称。唯一匹配直接显示字段名；跨表单同名键可消歧时显示“表单 / 字段”；无法匹配或无法消歧时显示“未识别的表单字段”并标记“需要人工核对”。
- 最后一个条件分支统一显示“其他条件均不满足时进入”，并提示后续数据仍需保证前序分支不成立；不把其自身残留条件当成独立判定。
- 手动分支显示“运行时选择该分支”并标记“待配置”；并行路由显示“全部分支并行必经”且归为目标平台自动确定，不生成虚假条件。
- F-006 不反推满足条件的具体表单值，也不执行真实条件验证；这些工作进入 F-007。

### 人员要求

- 审批和协同节点显示规则名称、会签或竞签方式、会签人数、范围摘要、表单人员字段以及无处理人是否跳过；没有配置时不能显示“正常”。
- 指定人员、角色、公司、部门、岗位等已经由目标配置明确的范围归为“目标平台自动确定”；有名称时显示名称，没有名称时只显示业务类型和数量，不展示业务 ID。
- 发起人、部门主管、分管副总、职级和扩展属性依赖发起人或运行组织关系，归为“运行时确定”；页面说明依赖项，不提前伪造人员名单。
- 审批人自选归为“待配置”，由 F-007 为该路径准备候选处理人；表单人员也归为“待配置”，并关联到对应表单字段要求。
- 无法识别的人员类型、缺失关键范围或自相矛盾的会签人数归为“需要人工核对”，但不阻断同页其他可识别要求。

### 节点动作与约束

- 发起节点需要配置“提交”；普通审批和协同节点需要配置处理结果；空节点、结束节点和纯路由结构不要求动作。
- 审批与协同的初始稳定动作只核对“同意/不同意”结果要求，实际意见、表单事件和业务前置校验留到 F-007 结合表单实现。
- 回退上一级、向当前节点添加审批人、转发等操作统一说明为“运行时可用性待核对”，不放入当前稳定动作候选，也不承诺后续一定自动化。
- 节点延时、自然日或工作日限制以及无处理人跳过作为只读约束展示；目标未配置时不补默认值。

### 四类状态

| 状态 | 含义 |
| --- | --- |
| 待配置 | F-007 必须为当前路径准备数据、人员或动作。 |
| 目标平台自动确定 | 目标流程配置已经决定，不要求工具侧再次选择。 |
| 运行时确定 | 必须等真实发起人、组织关系或任务状态形成后才能得到结果。 |
| 需要人工核对 | 目标元数据缺失、歧义或出现当前工具尚未确认的规则。 |

汇总只统计要求项，不把“目标平台自动确定”理解为整条路径已经可运行。只要 F-006 尚未进入后续配置，计划继续保持“待配置”。

### 新发起

## API

### 读取单条路径要求

`GET /api/plans/{planId}/execution-paths/{pathId}/requirements`

- 校验计划存在、路径属于计划且当前真实图仍能精确对应保存选择。
- 成功返回路径序号和名称、四类汇总、主线/并行分组以及每个业务节点的条件、人员、动作和约束。
- 请求无 body，不接受浏览器传入账号、来源、目标对象、入口、节点或分支 ID。
- 每次读取当前真实配置，不写数据库，不产生目标平台写操作。

### 稳定错误

| 错误 | 行为 |
| --- | --- |
| 计划或路径不存在、归属错误 | 复用现有计划与执行路径稳定错误，不泄露其他计划信息。 |
| 路径已不符合当前真实结构 | 返回 `EXECUTION_PATH_INVALID`，引导返回重新选择路径。 |
| 目标对象不可见、实例结束、配置缺失、会话失败、超时 | 复用现有 `TARGET_*` / 流程图错误映射并允许重试。 |
| 单项元数据未知或歧义 | 不让整页失败，返回“需要人工核对”项。 |
| 目标结构本身无法安全解析 | 返回现有流程结构异常，不输出半份要求。 |

## 代码边界

- `internal/adapter/target`：解码同一目标详情中的条件、审批配置、字段权限和关联表单引用，并按来源读取必要的表单字段元数据。
- `internal/analyzer`：复用执行路径遍历，生成主线/并行要求分组、四类状态和中文业务语义；不访问 HTTP 或数据库。
- `internal/service`：校验计划与路径归属，组织一次目标只读操作，处理路径失效和公开错误映射。
- `internal/api`：提供单条只读路由，不透传目标内部结构。
- `web/src/features/plans`：新增要求 API 类型、纯派生逻辑和核对页；不复制 Vue Flow，不建立编辑状态。
- `internal/repository`：只复用现有计划和路径读取，不增加表、字段或事务写入。

## 人工验收

1. 新发起计划选择一条含普通条件的路径，确认字段名、比较方式、固定值和连接关系为中文业务表达，页面不出现字段英文名或判断代码。
2. 核对目标最后一个条件分支，确认显示“其他条件均不满足时进入”；手动分支显示运行时选择，并行显示全部必经且汇合后公共节点不重复。
3. 核对指定人员、角色、组织范围、发起人、主管、审批人自选和表单人员节点，确认四类状态、范围摘要、会签/竞签、人数和无处理人跳过语义正确。
4. 核对发起、审批、协同、空节点和结束节点的动作要求；确认回退、添加审批人和转发只显示运行时限制，不被列为稳定可选动作。
5. 已发和待发只显示当前入口之后的要求，不出现已走过节点；切换多条路径时内容不会被旧请求覆盖。
6. 制造字段名称缺失、未知规则或范围不完整样本，确认单项进入“需要人工核对”而其他内容仍可查看。
7. 目标流程变化导致保存路径失效时，确认页面要求返回重新选择；目标超时或会话失败时可以重试且不丢失当前路径选择。
8. 核对无路径空状态、长路径和多并行分组滚动、深浅主题及减少动态效果；F-005 普通/页面全屏工具栏行为保持不变。
