## 单一用户结果

用户从待配置计划进入真实流程图后，可以新增一条路径，在当前可达的条件和手动分支上逐步选择目标线路；并行分支自动完整纳入同一路径。路径完整后保存到 MySQL，刷新页面、返回列表或重启服务后仍能恢复，计划列表显示真实路径数量。

## 真实行为依据

- F-004 已把目标 `conditionNodes`、`parallelNodes` 和 `branchExecuteType=custom_choose` 规范化为 `condition`、`parallel`、`manual` 边，并保留真实 `branchId` 和稳定顺序。
- `GroupApproveManage` 在手动分支时提供多个合法下一节点供选择；并行节点同时提供各活动分支的处理要求，因此路径选择必须区分“单选分支”和“全部并行分支”。
- 目标运行实例公开 `currentNodeProxyId`，待发任务使用 `flowNodeProxyId`；代理树节点 ID 与这些运行态代理节点引用属于同一 ID 空间，可用于确定已有实例的当前入口。并行活动入口必须保留为集合，不能压成一个节点。
- 当前创建页每个已发/待发计划只保存一个实例 ID；结合“每条执行路径独占一个真实实例”，本轮限制为最多一条路径。新发起尚未创建实例，可以为每条路径在后续各自创建新实例。

## 路径语义

### 入口

- `new`：从图的唯一真实根节点开始。
- `started`：精确重查保存实例，优先使用当前活动节点集合，退回当前节点代理 ID；所有入口都必须存在于刚读取的代理树。
- `pending`：精确重查保存实例的全部 `waiting_send` 任务，使用其当前节点代理 ID 集合作为入口。
- 当前入口为空、已结束或无法映射到代理树时不允许保存，页面说明当前流程已经不能配置后续路径。

### 遍历

从全部入口向后遍历：

- 普通业务节点沿唯一 `sequence` 边继续。
- 到达 `condition` 或 `manual` 路由时，当前路径必须选择恰好一条真实分支边；未选时形成一个待选择点。
- 到达 `parallel` 路由时，全部真实分支边自动纳入，不产生任选控件；每条并行支线中的条件/手动路由分别继续选择。
- 多条支线汇入同一真实后继时只访问一次；结束或无后继节点形成路径末端。
- 只有已选线路能够到达的路由才要求选择。请求带有不可达路由、同一路由重复选择或不属于该路由的分支时整条路径无效。

完整路径的持久化内容只是选择集合：

```json
{
  "choices": [
    { "routeNodeId": "真实路由节点 ID", "branchId": "真实分支 ID" }
  ]
}
```

并行边和普通节点由当前真实图派生，不重复保存。

## 来源差异

### 新发起

- 可以“新增路径”并从空草稿开始选择。
- 可以复制一条已保存路径；复制得到新的稳定路径序号和数据库记录，后续拥有独立实例、数据与动作。
- 不对相同分支选择去重；相同线路的不同记录是用户明确创建的独立测试路径。

### 已发与待发

- 一个计划只有一个保存实例，因此最多存在一条路径。
- 未保存时显示“选择当前实例后续路径”；保存后只允许继续编辑或删除，不显示新增、复制或重复路径入口。
- 选择只覆盖当前入口之后的线路；F-005 不修改、重置或重放实例已经走过的节点。

## 页面与交互

- 普通页面只显示真实流程和已保存路径的只读预览，不出现分支按钮；画布右上角并排保留“线路选择”和“页面全屏”。点击“页面全屏”只放大浏览，点击“线路选择”则自动进入页面全屏并开启编辑。
- 进入线路选择后移除横跨画布的路径工具条；右侧显示约 `320px` 的同表面色轻量悬浮面板，面板可收起、内部独立滚动，不使用抽屉遮住整图。
- 面板顶部集中路径切换、新增/复制和“还需选择 N 处”；中部用紧凑的只读迷你流向摘要实时展示当前已纳入的节点、所选分支和并行必经组，当前下一步突出显示；底部固定保存和删除操作。摘要只投影当前图分析结果，不建立第二套 Vue Flow、不保存快照。
- 新草稿不预选条件/手动分支。当前可达待选分支使用静止但明显的按钮状态；点击后已选线路改为高对比主题主色、更粗线条和明显方向流动，已纳入节点同步强化。同一路由其他候选停止动画并弱化但仍可读、可点击；尚未到达的后续分支保留静止弱化的名称，等流程到达后再开放选择，避免越级点击没有反馈。
- 并行入口统一显示“并行必经”，全部真实支线自动使用已纳入语义并流动，不允许取消；并行内部的待选点继续按真实从左到右顺序引导。
- 条件/手动分支真实点击区至少 `32px` 高，支持鼠标及 Enter/Space；已选、待选、未选状态同时使用文字、颜色、线宽和动画表达，不能只靠颜色。
- 进入选择态先定位第一处待选路由；每次选择后按确定性遍历顺序取得下一处。若下一处已在扣除右侧面板后的安全视口内，只强化并显示气泡；不在时以约 `220–300ms` 的平滑最小平移移入操作区，保持当前缩放且禁止 `fitView`。
- 下一处旁显示简短气泡“下一步：请选择一条分支（还剩 N 处）”；完成时改为“线路已完整，请保存”。气泡可关闭、短暂显示并使用 `aria-live`，不自动替用户选择或保存。
- 退出线路选择或页面全屏只关闭编辑展示，不清空草稿；再次进入时按钮文案和面板明确显示“继续选择”。页面全屏进入和退出继续保留 F-004 已验收的观察中心、纵向位置与缩放。
- 草稿完整前保存禁用并说明剩余数量；保存防重复点击。目标图变化或保存失败时保留草稿，重新读取最新图后只清除已无法对应的选择并继续引导，成功后切换为已保存状态并更新路径数量。
- 编辑已保存路径时在当前真实图上重新核对；缺失或不可达选择标记“流程已变化，需要重新选择”，用户补齐后通过 `PUT` 原位更新，路径序号不变。删除使用 Naive UI 确认框，只删除工具侧记录，不调用目标平台、不重排序号。
- `prefers-reduced-motion: reduce` 下所有线路停止流动和气泡位移动画，但已选线路仍以线宽、主题色、节点描边和文字保持清晰高亮。

## 数据库

使用三个向前迁移文件，避免 MySQL 驱动多语句依赖。

### `test_execution_paths`

- `id BIGINT UNSIGNED` 主键。
- `plan_id BIGINT UNSIGNED`，关联 `test_plans`。
- `sequence_no INT UNSIGNED`，计划内稳定序号，唯一键 `(plan_id, sequence_no)`。
- `create_key CHAR(36)`，全局唯一，用于创建重试幂等。
- `created_at`、`updated_at` 使用 UTC `DATETIME(3)`。

### `test_execution_path_choices`

- `path_id BIGINT UNSIGNED`，关联 `test_execution_paths` 并随路径删除。
- `route_node_id VARCHAR(100)`。
- `branch_id VARCHAR(100)`。
- 主键 `(path_id, route_node_id)`，保证一条路径在同一路由只能选择一个分支。

### `test_plans` 内部序号计数器

- 使用独立单语句向前迁移增加 `next_path_sequence_no INT UNSIGNED NOT NULL DEFAULT 1`，不进入计划 API。
- 创建路径时锁定计划行，以计数器和当前最大序号加一的较大值作为新序号，并在同一事务把计数器推进到下一个值。
- 删除路径不回退计数器；创建路径 1、2 后删除 2，再创建必须得到 3。

不保存节点名称、分支名称、流程来源、目标 ID、派生节点集合、流程图 JSON、目标响应或任何版本/指纹字段。

## API

### 流程图入口扩展

`GET /api/plans/{id}/flow-graph` 在现有响应增加：

```json
{ "entryNodeIds": ["当前真实入口节点 ID"] }
```

浏览器只用它计算可达选择，不展示 ID。

### 读取路径

`GET /api/plans/{id}/execution-paths`

- 按 `sequenceNo` 升序返回路径 ID、序号、选择和更新时间。
- 不在此接口伪造当前有效性；页面结合本次真实图计算完整、需补充或已失效状态。

### 创建路径

`POST /api/plans/{id}/execution-paths`

- 必须携带合法 `Idempotency-Key`。
- 请求只接受 `choices`。
- 后端重新读取计划和当前真实图，验证完整后在事务中分配下一个稳定序号并保存。
- 分配序号前锁定所属计划行，保证同一计划的并发创建不会得到相同序号。
- 相同键重试返回同一路径；不同键允许新发起创建相同选择的独立路径。

### 更新路径

`PUT /api/plans/{id}/execution-paths/{pathId}`

- 请求只接受完整 `choices`。
- 重新读取当前真实图后原位替换选择；路径序号不变。

### 删除路径

`DELETE /api/plans/{id}/execution-paths/{pathId}`

- 只删除属于该计划且尚未固化运行的路径。
- 成功返回 `204`；重复删除返回稳定的路径不存在错误，不伪装成功。

### 稳定错误

| 场景 | HTTP / 错误码 |
| --- | --- |
| 计划或路径 ID、请求格式错误 | `400 INVALID_ARGUMENT` |
| 计划不存在 | `404 PLAN_NOT_FOUND` |
| 路径不存在或不属于计划 | `404 EXECUTION_PATH_NOT_FOUND` |
| 路径选择缺失、额外、不可达或已不属于当前图 | `409 EXECUTION_PATH_INVALID` |
| 已发/待发已有一条路径 | `409 EXECUTION_PATH_LIMIT_REACHED` |
| 当前实例已结束或入口无法确定 | `409 TARGET_FLOW_NOT_CONFIGURABLE` |
| 计划已经产生运行事实、不能修改 | `409 PLAN_LOCKED` |
| 路径存储不可用 | `503 PLAN_STORAGE_UNAVAILABLE` |

目标登录、会话、不可见、结构和超时错误继续沿用 F-004 稳定映射。

## 代码边界

- `internal/adapter/target`：只扩充精确实例核对所需的当前代理节点字段，不保存路径。
- `internal/analyzer`：从图和选择计算可达子图、待选路由与完整性，不访问 HTTP 或数据库。
- `internal/model`：执行路径、分支选择和入口 DTO。
- `internal/repository`：路径仓储接口；`internal/repository/mysql` 负责迁移和事务 SQL。
- `internal/service`：编排计划锁定、当前图重读、来源数量限制、路径验证和事务保存。
- `internal/api`：稳定路径 API，不接受浏览器覆盖计划目标。
- `web/src/features/execution-paths`：路径 API、纯选择状态和工具栏。
- `web/src/features/flow-graph`：在现有节点和边上呈现选择状态，不引入持久化业务判断。

## 人工验收

1. 新发起直线流程：新增并保存零分支选择路径，刷新后仍显示“路径 1”，列表路径数量为 1。
2. 新发起复杂流程：条件/手动分支只能选一条，并行分支自动全部高亮；嵌套并行中的每个可达待选点都完成后才允许保存。
3. 新发起保存两条不同线路，再复制其中一条：序号稳定、同线路复制不会被去重，刷新和后端重启后仍存在。
4. 编辑已保存路径并改选同一路由的另一分支，确认原序号不变；删除一条路径后其他序号不重排，计划路径数量准确。
5. 已发和待发计划从当前节点继续选择，保存一条后不再出现新增/复制入口；不得把并行活动节点拆成多条路径。
6. 普通页面确认所有分支不可误触；分别点击“页面全屏”和“线路选择”，确认前者只浏览，后者自动全屏并出现右侧实时路径摘要，退出再进入时未保存草稿仍在。
7. 在选择模式点击条件/手动分支，确认只有已选和并行必经线路明显高亮并流动，未选线路停止流动但标签仍清楚可点；深浅主题及减少动态效果下状态都能辨认。
8. 每次选择后确认画布以不改变缩放的平滑最小移动定位下一处，并在节点附近提示剩余数量；全部选完后提示保存，不自动保存。复杂并行流程的摘要与主图保持一致且面板自身滚动顺滑。
9. 保存前让目标实例推进或改变流程结构，确认旧选择被拒绝并提示重新选择，不自动猜测或清空仍可对应的选择。
10. 模拟目标超时和数据库不可用，确认草稿仍在且可重试；浏览器和日志不出现 SID、凭证或目标接口原始响应，页面只使用选择所需的不透明节点/分支标识。
