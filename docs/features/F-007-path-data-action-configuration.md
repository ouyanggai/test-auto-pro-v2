- 状态：archived
- 归档时间：2026-09-03
- 当前依据：`docs/features/F-012-history-form-replay-action-orchestration.md`

## 保留范围

F-007 只保留已经验收的基础能力：

- 复用 F-005 的真实流程树、执行路径和分支选择；
- 读取并保存路径节点人员策略及目标平台返回的可见范围；
- 通过复制的 `form-runtime` 处理 FormMaking 和 `vue_custom`/NoFormFlow 页面；
- 运行时维护、会话隔离和目标平台只读请求策略。

表单正文始终按目标平台原始 JSON 传递。F-007 不生成普通字段值，不解析或维护测试工具自己的字段规则，不执行目标平台写请求，也不创建运行记录。

## 已取代范围

旧的表单生成、样本/种子、ConstraintIR、模板规则目录、路径准备、循环复制、运行输入预检和自定义页面字段桥接均由 F-012 直接删除，不保留兼容接口、别名、迁移回退或无历史兜底。

节点动作目录、动作门禁、独立动作排序和同一主实例场景编译属于 F-012；真实执行和运行记录属于后续功能。

## 交接

F-012 完成自动验证后状态为 `ready_for_manual`，人工核对通过前不得进入真实执行切片。
