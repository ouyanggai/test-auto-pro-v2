# F-010 全模板规则分析与 Vue 表单流程支持

- 状态：implementing
- 产品依据：`docs/PRODUCT.md` 的 F-010 模板规则目录与 Vue 业务页面
- 架构依据：`docs/ARCHITECTURE.md` 的 F-010 全模板规则分析与 Vue 表单流程
- 计划确认时间：2026-08-19

## 完成标准

- 目标平台当前确认的 196 个可用模板可通过“欧阳改”账号进入后台分析任务；规则持久化到本地目录，支持增量、全量和失败项重试。
- 表单协议明确区分 `formmaking`、`vue_custom` 和 `unknown`；没有 FormMaking JSON 的宿主 Vue 流程不得进入 `not_required`。
- FormMaking、自定义组件和 Vue 页面共用流程条件、身份上下文、生成、保存复验和批量准备规则，不为合同流程或单个模板建立专用生成分支。
- Vue 工作区加载宿主真实组件，回填字段、应用只读与路径锁定规则并执行真实 Element 表单校验；不在主应用或运行时重画一套普通表单控件。
- 已注册自定义组件按真实值形态和候选来源处理。外部对象没有真实候选时返回 `partial` 和中文字段原因，不伪造引用，不显示“组件不支持”。
- 设置页按服务端分页展示本地规则摘要和真实任务进度；目录分析不能扩大计划当前账号权限。
- 定向 Go/API/前端测试、Go 编译、主前端与 form-runtime 类型检查和生产构建实际通过后停在 `ready_for_manual`，不实现真实运行接口。

## 本地规则目录

- `test_template_rule_catalog` 以目标源模板为唯一键保存流程编码、名称、来源版本、分析器版本、渲染类型、规则正文、覆盖摘要、问题和分析时间。
- `test_template_rule_analysis_jobs` 保存分析模式、账号、真实总数、已处理、已覆盖、需处理、失败和终态。服务重启会把遗留活动任务改成可重试失败，避免活动锁永久占用。
- 增量分析只重读来源版本或分析器版本变化的模板；全量分析遍历账号当前可见模板；失败重试跳过已完成项。同账号只允许一个活动任务。
- 设置页 API 只返回摘要、覆盖计数和问题，不返回 `ruleData`、宿主源码、模板全文或目标内部标识。
- 规则目录使用“欧阳改”账号建立完整覆盖；计划详情、单条配置、样本和候选仍使用计划保存的账号，目录不改变目标权限。

## 渲染协议与规则提取

- `formmaking`：递归提取字段、容器、嵌套路径、真实选项、默认值、必填、数据源和可安全识别的脚本能力，继续由真实 FormMaking iframe 回显和校验。
- `vue_custom`：从宿主 `settings.js`、NoForm 配置文件、实际组件注册表和真实 `.vue` 文件提取页面入口、组件、字段路径、标签、类型、静态候选、必填、只读和候选来源。
- 宿主组件注册名与文件名不一致时，以 `hostVuePages.js` 的真实 import 和别名映射定位源码；`settings.js` 中同流程重复展示项不得覆盖已经确认的组件入口。
- 配置式 Vue 页面递归识别 `prop`、`nodeType/type`、`isRequire/required`、`disabled`、默认值和静态候选；标准 Element 页面识别实际 `v-model`、`el-form-item`、控件类型和 rules。
- 只读业务页通过 `detail/rawData` 回显并由 `getValues` 返回的数据进入运行时字段模型；无法证明入口、字段或动态协议时写入具体分析问题并归类 `unknown` 或 `needs_attention`。

## Vue 宿主运行时

- `HostVuePage` 只按规则目录确认的组件名加载宿主真实组件；当前注册范围覆盖预算、绩效、差旅、请款、借款及 NoForm 合同类页面。
- 运行时递归回填和读取宿主组件的 `form/initForm/editData/params/param/rawData/detail` 状态，应用字段权限与当前路径关键字段锁定，并调用宿主真实 `ElForm.validate`。
- 宿主页面原有保存、提交和取消按钮在配置工作区隐藏；既有 XHR/fetch 策略继续阻断流程提交、草稿、上传关联和业务写入，只允许已证明的只读请求携带当前会话 SID。
- 用户、部门、公司 ID/名称和发起人键同时注入 Vuex、内存认证和会话级 storage facade；销毁 iframe 时恢复原对象并清除会话数据。

## 统一生成与批量准备

- Vue 页面字段投影为生成器统一模板：数值、日期、文本和真实静态选项可生成；未知运行时字段按宿主组件处理；文件和外部业务对象保持人工或真实候选边界。
- 单条生成和批量任务都通过本地目录读取同一份页面/组件规则。`complete` 只表示当前可证明字段和完整路径均通过；候选不足返回 `partial`，未知页面协议返回 `blocked`。
- 已保存人工表单不覆盖；“换一组”只替换生成器拥有的字段。服务端保存重新校验字段形状、可编辑范围、当前路径条件、日期关联和完整线路。
- 批量任务一次读取规则快照、身份目录、模板和同流程近期样本，继续分页处理路径；单条 Vue 页面缺少真实候选只影响该路径。

## 不包含

- 不新增真实运行、调度、运行记录或目标平台业务写入。
- 不引入 LLM、外部队列、中间件或单表单专用适配器。
- 不提交目标参考源码、模板原始响应、凭证、缓存、构建产物、日志或 PID。
