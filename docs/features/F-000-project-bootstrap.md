- 根目录 pnpm workspace、两个前台热更新终端、前台启动命令和 F-000 分类测试。

- 数据库、Docker、微服务和部署编排。

## 人工验收

1. 在一个终端执行 `pnpm dev:backend`，保持运行并观察 Air 日志。
2. 在另一个终端执行 `pnpm dev:frontend`，打开 `http://127.0.0.1:19000`。
3. 核对顶栏横跨全宽，底部与侧栏右侧均有肉眼可见的 1px 分隔线；浅色时顶栏、侧栏和主内容完全同色，深色时也完全同色；浏览器本身不滚动，只有内容超出时主内容区滚动。
4. 核对左侧只显示产品名；顶栏中间没有占位状态文字，最右侧仅有“深色/浅色”主题工具栏入口。点击后确认顶栏、侧栏、内容、文字、边线和选中态均随主题切换；刷新后确认主题保持。
5. 点击侧栏右边的圆形箭头，确认收缩后菜单文字隐藏、主内容扩大；收缩后的圆形按钮完整位于左侧 viewport 内、真实点击区至少为 `32px × 32px`，仍可恢复侧栏；不出现额外图标。
6. 核对“测试计划、运行记录、系统设置”三个中文入口，并依次点击确认路由和占位内容。
7. 打开 `http://127.0.0.1:19080/api/health`，核对固定 JSON。
8. 修改任意项目 Go 源码并保存，核对后端终端显示重编译和重新运行。
9. 在两个终端分别按 `Ctrl+C` 停止前端和后端。
