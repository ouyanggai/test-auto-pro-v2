# 测试策略

## 风险分层

- 单元测试：快速验证纯逻辑，分别放在 `test/unit/backend/` 和 `test/unit/frontend/`。
- 契约测试：验证稳定 HTTP 响应和接口边界，放在 `test/contracts/`。
- 集成测试：验证前台开发命令、端口、热重载、代理和多组件协作，放在 `test/integration/`。
- 手工验收：记录需要用户在浏览器或真实目标平台核对的步骤，放在 `test/manual/`。
- 固定样本：非敏感测试输入放在 `test/fixtures/`。

## 执行原则

- 所有测试用例和测试脚本必须保存在根目录 `test/` 并分类。
- 日常只运行当前功能相关测试，不运行无关全量测试。
- 自动验证必须实际执行；视觉与真实目标交互由用户手工验证，不自动启动浏览器。
- 测试不得依赖或写入真实凭证，不修改目标平台数据。

## F-000 验证范围

- Go build 与健康接口精确响应。
- 前端类型检查、生产构建和 `pnpm dev:f` 开发服务器 smoke。
- `pnpm dev:b` 的 Air 配置、健康接口和 Go 源码变更后的热重载。
- 两个前台命令均以前台日志和 `Ctrl+C` 停止，不建立 PID 或后台进程管理。
- 应用壳主题默认值、切换与 `localStorage` 持久化源码契约，以及 `NLayoutHeader bordered`/`NLayoutSider bordered` 的 1px 分隔线、无嵌入色的统一表面、至少 `32px × 32px` 且收缩后完整可点的 Naive UI 圆形触发器和主内容滚动边界。
- 13 个参考仓库的远端、分支、HEAD 与清洁状态。
- 参考仓库脏工作树保护必须拒绝同步。

## F-001 验证范围

- 计划名称、状态筛选及清空对本地 mock 数据的纯函数行为。
- 四种计划状态到唯一主要操作的映射。
- 未验证账号仅允许新发起来源；账号编辑后的验证失效、来源回退和选择清理契约。
- 流程模板、已发流程、待发流程三类本地候选字段语义、搜索过滤和固定批次追加边界。
- `/plans`、`/plans/new` 路由、Naive UI 表格、两列上置标签栅格、三类独立虚拟列表与 `FormRules` 动态条件规则。
- 字段就地错误、单次短暂消息、无页面级错误汇总、定时启动和隐藏字段旧校验清理。
- F-001 源码不包含后端、目标平台请求或 SID 生成逻辑。
- 流程选择外壳高度稳定、稳定吸顶返回入口、语义分隔线、减少动态效果和仅在目标未完整可见时的最小距离引导。
- 静态提示边界和内容区水平滚动配置。
- 前端类型检查与生产构建；视觉、主题和 1366×768 滚动效果由用户手工核对，不自动启动浏览器。

## F-002 验证范围

- 后端单元测试：`TARGET_*` 必填与非敏感默认值、本机文件加载、进程环境优先级、缺失/非法文件、测试路径隔离、敏感值不进入错误、密码加密边界、会话 TTL、账号隔离、同账号并发去重、不同账号不互阻、一次重登上限。
- API 契约测试：账号验证、模板列表、实例列表的参数、分页、成功 DTO、已发 `statusName`、模板备注与表单关联计数、稳定错误码，以及所有公开 JSON 不含 SID、密码、AES key、customerCode 或 platformCode。
- 假目标集成测试：真实登录请求结构、SID body/query/header 三处传递、模板读取只调用已批准模板接口、已发八种状态到中文 `statusName` 的映射、模板/已发/待发请求与字段映射、空列表、HTTP 与业务会话失效、一次重登、登录拒绝、坏响应、坏分页、目标 5xx、超时和 context 取消。
- 前端单元测试：250ms 搜索防抖、取消、account/source/query/version 迟到保护、分页追加去重、失败页重试、会话最终失效后的验证清理、三类 DTO 映射，以及模板 `groupName` 标签、空分组、编码不展示与不参与本地搜索、已发全部中文状态与未知值中文兜底、备注空值/长值、辅助字段和无主状态展示。
- 前端结构测试：生产新建页不导入候选 mock，继续使用吸顶返回入口、分隔线和独立内容滚动；断言 `96px` 虚拟行、`480px` 视口、`574px` 稳定外壳、备注两行省略、减少动态效果及过期技术文案已移除。
- 本机配置集成测试：使用临时 V1 YAML 和动态测试值运行同步命令，验证键映射、自动加载、`0600` 权限和完整性检查；不得读取开发者真实 `.env.local`。
- `test/run-f002.sh` 只聚合上述当前范围测试、Go build、`vue-tsc` 与 Vite build；不连接真实目标平台，不启动浏览器。
- 真实账号身份、三类真实数据和浏览器视觉由用户按 `test/manual/F-002.md` 现场验收。

## F-003 验证范围

- 后端单元测试：计划数据库配置、库名约束、计划字段与枚举校验、串并约束、未来定时、幂等键和仓储错误映射。
- API 契约测试：创建、列表、详情的成功和稳定错误；公开响应不得包含 `create_key`、SID 或凭证。
- 本机配置集成测试：从临时 V1 `runnerDb` 样本安全同步 `PLAN_DB_*`，保留 `TARGET_*`，验证 `0600` 权限并拒绝复用 V1 原数据库。
- MySQL 集成测试：先确认当前独立库只含 `schema_migrations` 和 `test_plans`；再创建经过严格前缀校验的随机临时库，实际验证迁移、CRUD、筛选、幂等、重复迁移和重连可读，结束只删除本次临时库。
- 前端单元与结构测试：真实创建请求、同次重试复用幂等键、loading 防重复、失败保留、成功导航、真实列表筛选与错误恢复、详情无路径状态，以及生产代码不导入计划 mock、不引入 Vue Flow/dagre。
- `test/run-f003.sh` 只聚合上述 F-003 测试、Go build、`vue-tsc` 和 Vite build；不启动浏览器。
- 计划创建后的页面、视觉、筛选与前后端重启持久化由用户按 `test/manual/F-003.md` 人工验收。

## F-004 验证范围

- 后端单元测试：计划持久化身份透传、节点类型归一、直线、条件、手动分支、并行、嵌套、汇合、共享节点去重、未知普通节点、循环、关键 ID、空分支以及 500 节点和 200 深度边界。
- API 契约测试：流程图成功 DTO、计划不存在、目标不可见、空结构、结构异常、登录失败、会话失效、配置缺失、不可用和超时；公开响应不得包含 SID、`flowProxyId`、目标原文、审批配置或字段权限。
- 假目标集成测试：新发起先精确核对模板再读取模板树；已发和待发先按实例 ID 精确取得当前 `flowProxyId`，再用代理 ID 读取实例树；会话失效时整条核对与详情链只重放一次。
- 前端单元测试：dagre `TB` 布局确定性、分支名称、节点只读属性、稳定错误、请求取消和每个计划首次图数据的一次适配。
- 前端结构测试：Vue Flow、Controls、dagre 依赖和样式完整，画布允许平移/缩放但禁止拖动节点、连接、选择和删除，不引入路径选择或保存。
- `test/run-f004.sh` 只聚合上述 F-004 测试、Go build、`vue-tsc` 和 Vite build；不启动浏览器、不连接长期真实目标数据。
- 三类真实流程、复杂分支、画布操作和深浅主题由用户按 `test/manual/F-004.md` 人工验收。
