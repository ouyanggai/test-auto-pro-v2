# 测试策略

## 风险分层

- 单元测试：快速验证纯逻辑，分别放在 `test/unit/backend/` 和 `test/unit/frontend/`。
- 契约测试：验证稳定 HTTP 响应和接口边界，放在 `test/contracts/`。
- 集成测试：验证前台开发命令、端口、热重载、代理和多组件协作，放在 `test/integration/`。
- 手工验收：记录需要用户在浏览器或真实目标平台核对的步骤，放在 `test/manual/`。
- 固定样本：非敏感测试输入放在 `test/fixtures/`。

## 执行原则

- 所有测试用例和测试脚本必须保存在根目录 `test/` 并分类。
- 日常只运行当前功能相关测试，不运行无关全量测试。
- 自动验证必须实际执行；视觉与真实目标交互由用户手工验证，不自动启动浏览器。
- 测试不得依赖或写入真实凭证，不修改目标平台数据。

## F-000 验证范围

- Go build 与健康接口精确响应。
- 前端类型检查、生产构建和 `pnpm dev:frontend` 开发服务器 smoke。
- `pnpm dev:backend` 的 Air 配置、健康接口和 Go 源码变更后的热重载。
- 两个前台命令均以前台日志和 `Ctrl+C` 停止，不建立 PID 或后台进程管理。
- 应用壳主题默认值、切换与 `localStorage` 持久化源码契约，以及 `NLayoutHeader bordered`/`NLayoutSider bordered` 的 1px 分隔线、无嵌入色的统一表面、至少 `32px × 32px` 且收缩后完整可点的 Naive UI 圆形触发器和主内容滚动边界。
- 13 个参考仓库的远端、分支、HEAD 与清洁状态。
- 参考仓库脏工作树保护必须拒绝同步。

## F-001 验证范围

- 计划名称、状态筛选及清空对本地 mock 数据的纯函数行为。
- 四种计划状态到唯一主要操作的映射。
- 未验证账号仅允许新发起来源；账号编辑后的验证失效、来源回退和选择清理契约。
- 流程模板、已发流程、待发流程三类本地候选字段语义、搜索过滤和固定批次追加边界。
- `/plans`、`/plans/new` 路由、Naive UI 表格、两列上置标签栅格、三类独立虚拟列表与 `FormRules` 动态条件规则。
- 字段就地错误、单次短暂消息、无页面级错误汇总、定时启动和隐藏字段旧校验清理。
- F-001 源码不包含后端、目标平台请求或 SID 生成逻辑。
- 流程选择外壳高度稳定、稳定吸顶返回入口、语义分隔线、减少动态效果和仅在目标未完整可见时的最小距离引导。
- 静态提示边界和内容区水平滚动配置。
- 前端类型检查与生产构建；视觉、主题和 1366×768 滚动效果由用户手工核对，不自动启动浏览器。

## F-002 验证范围

- 后端单元测试：`TARGET_*` 必填与非敏感默认值、敏感值不进入错误、密码加密边界、会话 TTL、账号隔离、同账号并发去重、不同账号不互阻、一次重登上限。
- API 契约测试：账号验证、模板列表、实例列表的参数、分页、成功 DTO、稳定错误码，以及所有公开 JSON 不含 SID、密码、AES key、customerCode 或 platformCode。
- 假目标集成测试：真实登录请求结构、SID body/query/header 三处传递、模板/已发/待发请求与字段映射、空列表、HTTP 与业务会话失效、一次重登、登录拒绝、坏响应、坏分页、目标 5xx、超时和 context 取消。
- 前端单元测试：250ms 搜索防抖、取消、account/source/query/version 迟到保护、分页追加去重、失败页重试、会话最终失效后的验证清理，以及三类 DTO 映射。
- 前端结构测试：生产新建页不导入候选 mock，继续使用固定高度虚拟候选区、吸顶返回入口、分隔线和独立内容滚动。
- `test/run-f002.sh` 只聚合上述当前范围测试、Go build、`vue-tsc` 与 Vite build；不连接真实目标平台，不启动浏览器。
- 真实账号身份、三类真实数据和浏览器视觉由用户按 `test/manual/F-002.md` 现场验收。
