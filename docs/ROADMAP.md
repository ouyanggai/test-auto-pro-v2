## 当前与后两项

### F-003 最小计划持久化（已验收）

引入 MySQL，将新建页已经确认的计划名称、账号、流程来源、目标对象、串并方式和可选定时时间保存为“待配置”计划；计划列表改读真实数据，并提供可恢复的继续配置入口。

详细范围、MySQL 边界、API、验证和人工门禁见 `docs/features/F-003-minimal-plan-persistence.md`。用户已确认计划可正常读取，F-003 于 2026-07-28 进入 `accepted`。

### F-004 只读真实流程图（已验收）

使用已保存计划的账号、来源和目标对象重新核对当前可见记录；新发起读取模板树，已发和待发读取各自实例代理树。使用 Vue Flow 和流程专用树布局，只读显示真实节点、条件/手动分支、并行、嵌套与汇合，提供平移、缩放、页面全屏、适配以及稳定错误反馈。

详细范围、来源接口、图映射、页面交互、自动验证和人工门禁见 `docs/features/F-004-read-only-real-flow-graph.md`。用户于 2026-07-28 要求开始下一项任务，F-004 进入 `accepted`。

### F-005 执行路径选择与持久化（已验收）

在已核实的真实流程结构上逐条选择条件/手动分支，并把并行分支作为同一路径的全部必经线路；首次建立路径表与分支选择表，支持完整路径新增、编辑、复制和删除。新发起可保存多条，已发/待发因当前计划只绑定一个实例而最多一条。

详细范围、路径语义、当前节点入口、数据表、API、画布交互、验证和人工门禁见 `docs/features/F-005-execution-path-selection.md`。普通画布只保留文字页面全屏按钮，页面全屏后才显示路径列表、受来源/数量限制的新增入口和文字退出按钮；用户于 2026-08-07 明确要求开始下一项任务，F-005 进入 `accepted`。

### F-006 路径要求分析（当前，待人工复验）

读取所选路径上的真实条件、人员规则和标准节点动作，形成供后续配置直接消费的只读要求结果。独立核对页面、入口和页面专用前端代码已删除，后端分析与 API 保留并通过聚合验证；详细范围见 `docs/features/F-006-path-requirements-review.md`，当前等待用户人工复验，不开始 F-007。

### F-007 路径数据与动作配置（下一项）

依据 F-006 核对出的要求，为每条执行路径准备相互独立的表单数据、人员和节点动作；具体范围在 F-006 人工验收后单独规划。

### 后续运行准备与真实执行（后两项）

检查路径配置完整性，生成独立运行记录并调用目标平台真实接口执行；具体切片不在 F-006 预判实施。

## 推进规则

当前功能到达 `ready_for_manual` 后停止。只有用户明确验收并批准下一项，路线图才能推进。
