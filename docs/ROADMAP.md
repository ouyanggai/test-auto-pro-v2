## 当前与后两项

### F-012 历史业务数据回放与节点动作编排（等待批准）

当前唯一现行计划见 `docs/features/F-012-history-form-replay-action-orchestration.md`。目标是完成 FormMaking 与 `vue_custom`/NoFormFlow 自定义表单历史实例候选、目标原始表单数据快照、路径级来源覆盖、分支窄补丁、批量回放、真实动作目录、动作门禁和同一主实例场景编译。

本切片统一支持有 FormMaking 模板和无表单自定义页面，是否存在表单不影响数据驱动链路；目标历史表单数据不经测试工具包装，直接交给复制的 `form-runtime`。不接入大模型，不生成不存在于历史数据中的普通字段值，不创建运行记录，不调用目标平台写接口。无法完整读取、目标 runtime 无法接收或路径无法复验时进入 `needs_input`，不静默跳过。发起“保存草稿”和审批“暂存当前表单”分离；加签、移交、取回、撤回、回退、催办、转发和关注按目标实时上下文判定。用户动作以独立记录排序，系统插入恢复与导航步骤，无法恢复的顺序保存时阻止。

用户已决定清空本测试工具数据库业务数据并从新模型开始，保留 `schema_migrations` 和运行时维护能力，绝不触碰目标平台数据库。实施前必须先获得用户对本文件的明确批准；批准后只派发固定实施任务，自动验证完成后停在 `ready_for_manual`。

详细任务、接口、数据表、测试分类和人工门禁见上述功能文件。
