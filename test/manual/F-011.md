# F-011 智能表单统一契约基线人工核对

本切片没有新增页面或改变产品交互，只需确认既有表单工作区没有回退。

1. 打开一条可配置路径的 FormMaking 表单，执行“智能生成”，确认表单正常回填。
2. 人工修改一个普通字段后执行“换一组”，确认人工值保留，路径锁定字段仍不可编辑。
3. 保存并刷新，确认级联、明细行、自定义组件值及其虚拟字段仍能回显。
4. 打开一条 `vue_custom` 表单，确认真实宿主页面仍能加载、校验和读取字段。
5. 关闭表单工作区后重新打开另一条路径，确认旧表单响应不会回写新页面。
6. 在 Network 中确认目标写请求仍被阻断；本切片没有把请求策略切换为清单默认拒绝。

通过后请明确回复 F-011 人工验收通过。未通过时请提供路径、操作步骤、页面提示和对应 Network 请求。
