# F-004 只读真实流程图人工验收

## 启动与准备

1. 在项目根目录两个终端分别运行 `pnpm dev:b` 和 `pnpm dev:f`，不要展示 `.env.local` 内容。
2. 准备同一可验证账号当前可见的一个流程模板、一个已发流程实例和一个待发流程实例，分别创建计划。
3. 从 `/plans` 对三条计划点击“继续配置”；验收结束后在两个终端分别按 `Ctrl+C`。

## 三类真实结构

1. 新发起计划应显示当前模板的真实节点树。
2. 已发和待发计划应显示各自实例的当前代理树；不得显示模板后来修改后的结构，也不得把实例 ID 当作代理 ID 请求详情。
3. 页面显示节点名称、发起/审批/协同/条件/手动分支/并行/空节点/结束类型和真实分支名称，不显示节点编码、策略编码或代理 ID。

## 复杂结构与画布

1. 先用直线流程核对所有业务节点沿同一垂直主干排列，节点之间只有垂直线，没有横向绕行。
2. 使用包含三个分支且分支深度分别为一、二、三层的流程：三个入口应按目标顺序从左到右且顶部对齐；同一路由只有一条水平分叉轨，各分支末端只有一条水平汇合轨，真实共享后继位于分支组下方中央。
3. 使用包含条件、手动分支、并行和两级嵌套路由的流程：嵌套路由应在所属分支列内展开并推开相邻分支，节点矩形和连线不能重叠或交叉；路由只形成透明树干，不显示路由卡片或“条件路由”文字。
4. 核对连线始终有清晰静态底线，低对比度流动标记沿流程方向移动且不遮挡分支名；开启系统“减少动态效果”并刷新后，流动停止但静态线仍清晰。
5. 首次进入时根业务节点应以可读大小出现在画布上方中央，不自动适配整图；拖动或缩放后，窗口变化及同一计划重试不应重置当前位置。右下角适配控件仍可主动查看全貌。
6. 先在正常画布中平移并缩放到任意位置，再进入和退出页面全屏：当前水平观察中心应仍位于新容器中央，纵向浏览位置和缩放不变，不会重新适配整图或跳到页面中部。
7. 在全屏切换尚未完成时立刻再次点击退出或按 `Esc`，确认先完成进入补偿再完成退出补偿；最终回到普通画布时，水平位置、纵向位置和缩放均与切换前一致，文档滚动也已恢复。
6. 点击右上角“页面全屏”，确认画布铺满网页内容视口而浏览器标签栏和地址栏仍保留；拖动或缩放后分别使用“退出全屏”和 `Esc` 退出，确认退出前后当前浏览位置不被重置，页面滚动恢复正常。
7. 节点不可拖动、连接、删除、选择或选为执行路径；画布仍可拖动、滚轮缩放和使用右下角控件。
8. 切换深浅主题，核对普通与页面全屏画布都和内容区表面一致，节点、正交边、分支文字和控件清晰，没有阴影或异色底块。

## 失败与安全

1. 使用当前账号不再可见的目标，或让待发任务处理完成后重试，应说明目标流程当前不可读取，不显示保存名称拼出的假图或上一次图。
2. 使用尚未配置节点的流程，应显示“目标流程暂未配置节点”；结构异常时，计划摘要仍保留，画布稳定区域只显示“目标流程结构异常”和“重试”，不得显示半张图、真实节点 ID 或底层异常原文。点击重试应重新读取流程图。
3. 临时制造目标超时或不可用，计划摘要应保留并提供重试；恢复后可以重新读取。
4. 浏览器响应和后端终端不得出现 SID、`flowProxyId`、登录凭证、目标原文、审批配置或字段权限。
5. 打开包含“外层分支内嵌无独立后继的并行/手动路由”的计划，确认内层各出口只汇入外层共享后继一次：页面不报结构异常，内层各有独立分叉轨，外层只有一条共享汇合轨，节点不重复、不重叠。

## 验收结论

- [ ] 新发起、已发、待发三类真实结构正确。
- [ ] 主干垂直，分支从左到右且顶部对齐，每个分叉和汇合分别只使用一条水平轨。
- [ ] 条件、手动、并行和嵌套路由只显示正交树干，节点不重叠、线路不交叉，汇合关系正确。
- [ ] 静态线清晰且方向流动克制，减少动态效果时动画停止。
- [ ] 根节点初始缩放可读，大图可拖动浏览，适配控件按需可用。
- [ ] 页面全屏保留浏览器栏，按钮和 `Esc` 均可退出且不重置当前视口。
- [ ] 平移、缩放和深浅主题通过，节点始终只读。
- [ ] 空结构、不可见、异常、超时和不可用反馈准确。
- [ ] 用户明确验收通过后，才可将 F-004 标为 `accepted`。
