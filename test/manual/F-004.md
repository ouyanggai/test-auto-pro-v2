# F-004 只读真实流程图人工验收

## 启动与准备

1. 在项目根目录两个终端分别运行 `pnpm dev:b` 和 `pnpm dev:f`，不要展示 `.env.local` 内容。
2. 准备同一可验证账号当前可见的一个流程模板、一个已发流程实例和一个待发流程实例，分别创建计划。
3. 从 `/plans` 对三条计划点击“继续配置”；验收结束后在两个终端分别按 `Ctrl+C`。

## 三类真实结构

1. 新发起计划应显示当前模板的真实节点树。
2. 已发和待发计划应显示各自实例的当前代理树；不得显示模板后来修改后的结构，也不得把实例 ID 当作代理 ID 请求详情。
3. 页面显示节点名称、发起/审批/协同/条件/手动分支/并行/空节点/结束类型和真实分支名称，不显示节点编码、策略编码或代理 ID。

## 复杂结构与画布

1. 使用包含条件、手动分支、并行和嵌套分支的流程，核对每个分支入口及其汇合到同一后继节点的方向。
2. 首次进入时流程图应自然适配可视区域；随后拖动画布、滚轮缩放并使用右下角缩放和适配控件。
3. 节点不可拖动、连接、删除或选为执行路径；窗口尺寸变化不应反复把视口拉回中心。
4. 切换深浅主题，核对画布与内容区表面一致，节点、边、分支文字和控件清晰，没有阴影或异色底块。

## 失败与安全

1. 使用当前账号不再可见的目标，或让待发任务处理完成后重试，应说明目标流程当前不可读取，不显示保存名称拼出的假图或上一次图。
2. 使用尚未配置节点的流程，应显示“目标流程暂未配置节点”；结构异常时不得显示半张图。
3. 临时制造目标超时或不可用，计划摘要应保留并提供重试；恢复后可以重新读取。
4. 浏览器响应和后端终端不得出现 SID、`flowProxyId`、登录凭证、目标原文、审批配置或字段权限。

## 验收结论

- [ ] 新发起、已发、待发三类真实结构正确。
- [ ] 条件、手动分支、并行、嵌套和汇合关系正确。
- [ ] 平移、缩放、适配和深浅主题通过，节点始终只读。
- [ ] 空结构、不可见、异常、超时和不可用反馈准确。
- [ ] 用户明确验收通过后，才可将 F-004 标为 `accepted`。
