# F-000 手工验收

1. 在第一个终端执行 `pnpm dev:backend`，确认 Air 显示构建并监听 `127.0.0.1:19080`。
2. 在第二个终端执行 `pnpm dev:frontend`，打开 `http://127.0.0.1:19000`，核对产品名称为“流程自动化测试平台”。
3. 依次点击“测试计划、运行记录、系统设置”，确认路由分别为 `/plans`、`/runs`、`/settings`，占位内容与入口一致。
4. 打开 `http://127.0.0.1:19080/api/health`，确认只显示 `{"status":"ok","service":"test-auto-pro","version":"dev"}`。
5. 修改一个项目 Go 源码文件并保存，确认后端终端显示重新构建、重新运行，健康接口仍可访问。
6. 在两个开发终端分别按 `Ctrl+C`，确认前后端均停止。

完成上述核对后，由用户明确决定是否把 F-000 从 `ready_for_manual` 推进到 `accepted`。未明确验收前不得开始 F-001。
