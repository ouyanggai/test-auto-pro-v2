# F-000 手工验收

1. 在第一个终端执行 `pnpm dev:backend`，确认 Air 显示构建并监听 `127.0.0.1:19080`。
2. 在第二个终端执行 `pnpm dev:frontend`，打开 `http://127.0.0.1:19000`，核对产品名称为“流程自动化测试平台”。
3. 核对顶栏横跨全宽、侧栏从顶栏下方开始，顶栏底部和侧栏右侧均为肉眼可见的 1px 分隔线；浅色时顶栏、侧栏和主内容完全同色，深色时也完全同色；页面不出现浏览器滚动条，内容超出时仅主内容区域滚动。
4. 核对左侧仅有“流程自动化测试平台”；顶栏中间为空，右侧只有“深色/浅色”主题工具栏入口，不出现“项目初始化”。点击主题入口，确认深色主题的顶栏、侧栏、内容、文字、边线和菜单选中态均正确切换；刷新后确认仍为深色，再切回浅色。
5. 点击侧栏右侧的 Naive UI 圆形箭头，确认侧栏收缩后菜单文字消失且主内容扩大；收缩后的圆形按钮完整留在左侧 viewport 内，点击区不小于 `32px × 32px`，再次点击可恢复侧栏，不出现额外图标。
6. 依次点击“测试计划、运行记录、系统设置”，确认路由分别为 `/plans`、`/runs`、`/settings`，占位内容与入口一致。
7. 打开 `http://127.0.0.1:19080/api/health`，确认只显示 `{"status":"ok","service":"test-auto-pro","version":"dev"}`。
8. 修改一个项目 Go 源码文件并保存，确认后端终端显示重新构建、重新运行，健康接口仍可访问。
9. 在两个开发终端分别按 `Ctrl+C`，确认前后端均停止。

完成上述核对后，由用户明确决定是否把 F-000 从 `ready_for_manual` 推进到 `accepted`。未明确验收前不得开始 F-001。
