# F-000 手工验收

1. 执行 `make dev`，确认命令报告前后端已就绪。
2. 打开 `http://localhost:19000`，核对产品名称为“流程自动化测试平台”。
3. 依次点击“测试计划、运行记录、系统设置”，确认路由分别为 `/plans`、`/runs`、`/settings`，占位内容与入口一致。
4. 打开 `http://localhost:19080/api/health`，确认只显示 `{"status":"ok","service":"test-auto-pro","version":"dev"}`。
5. 执行 `make status` 和 `make logs`，确认能看到两个进程状态及各自日志。
6. 执行 `make stop`，再次执行 `make status`，确认前后端均已停止。

完成上述核对后，由用户明确决定是否把 F-000 从 `ready_for_manual` 推进到 `accepted`。未明确验收前不得开始 F-001。
