# F-006 路径要求分析人工复验

## 准备

1. 使用现有本机配置启动前后端，打开一个已经保存执行路径的测试计划。
2. 本轮只复验独立核对页面已移除且 F-005 没有回退；后端分析能力由 `./test/run-f006.sh` 自动验证。

## 用户入口已移除

1. 打开计划路径配置页，确认标题区和画布右上角均不显示“核对路径要求”。
2. 确认应用正常导航中不存在独立路径要求页面；直接访问旧地址 `/plans/{计划ID}/requirements` 不应再进入 F-006 核对页。
3. 页面不得出现为 F-007 提前创建的表单、人员、动作配置控件。

## F-005 回归

1. 普通画布仍只显示带文字的“页面全屏”按钮。
2. 进入页面全屏后，确认已保存路径、新增路径及带文字的退出全屏入口仍按来源和数量限制显示。
3. 核对路径新增、只读查看、编辑、复制、删除和一键生成能力没有因删除 F-006 页面而变化。
4. 保存失败仍保留草稿，保存成功仍回到普通画布；取消和退出确认行为保持不变。

## 后端能力自动证据

`./test/run-f006.sh` 必须继续通过以下范围：

- `GET /api/plans/{planId}/execution-paths/{pathId}/requirements` 的归属隔离、当前真实图重验和公开字段安全。
- 新发起、已发、待发的目标树与表单字段元数据读取，以及超时、取消、会话重放和响应大小边界。
- 条件中文语义、`contains` 真实方向、人员规则、标准动作、字段权限、跨表单消歧与无法消歧降级。
- 多活动入口并行分组、可证明共同汇合只回主线一次、无共同后继时不伪造汇合。
- F-004/F-005 必要回归、Go build、Vue 类型检查、生产构建和 `git diff --check`。

## 通过标准

- 用户界面不再存在独立“路径要求核对”入口、路由或页面。
- F-005 路径选择和页面全屏行为无回退。
- 后端只读要求分析、API 和安全边界仍由完整自动验证覆盖。
- F-006 不修改数据库、路径、计划状态或目标平台，也不开始 F-007。
