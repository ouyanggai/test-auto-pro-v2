# F-007 真实表单与逐节点配置人工验收

## 前置

- 启动后端、主前端和独立表单运行时；准备一个已验证账号。
- 准备一条新发起路径，以及可选的已发/待发路径。新发起模板最好包含布局容器、必填字段、默认值、选项、条件分支和至少一个目标自定义组件。
- 自动测试会验证迁移、协议、同步状态机和构建；本清单只核对真实浏览器交互、目标模板呈现和现场只读请求。

- 已完整执行 `./test/run-f007.sh`：F-007 单元/契约/目标适配/前端/运行时/维护流水线及 F-004/F-005/F-006 必要回归全部通过。
- 已从本机忽略配置加载 `PLAN_DB_*`，临时 MySQL 正向迁移、配置事务/并发幂等/级联、维护任务单活动/租约/fencing 全部通过；Go build、主前端 `vue-tsc`、主前端和 form-runtime 生产构建、`git diff --check` 通过。

## 路径与节点画布

1. 从 `/plans` 打开没有已保存路径的待配置计划；普通详情页只能先“配置路径”，不能出现无效“配置节点”。使用既有 F-005 新增并保存路径，确认路径选择、命名、编辑、复制、删除和页面全屏没有变化。
2. 回到计划详情，每条已保存路径应显示稳定序号、名称、配置状态和“配置节点”。点击后进入 `/plans/{planId}/paths/{pathId}/configure`，主体是当前路径的 Vue Flow 画布，不是整页字段表单。
3. hover、键盘聚焦并点击当前路径上的业务节点。节点应有清晰 pointer、hover、focus 和选中反馈，右侧详情立即切换；状态角标不遮挡节点名称，路径外上下文弱化且不可配置。
4. 右侧只出现人员、动作、节点规则和当前节点保存，不出现表单字段。保存当前节点后只能完成当前节点；失败保留草稿和选中节点，响应不确定时对账后以服务端状态为准，不能提示失败后刷新却静默完成。
5. 依次检查发起、审批/协同、条件、手动分支、并行/汇聚/空/结束。固定/角色/组织/运行时人员规则保持只读，只有模板允许且目标返回合法候选时才可选；可跳过会签零人合法，非零仍满足最低/最高人数。

## 真实表单工作区与智能生成

6. 点击顶部“表单数据”。节点画布和节点侧栏应由尽量全宽的独立 FormMaking iframe 工作区替换，工具条固定显示“返回节点画布”“智能生成”“换一组”“恢复已保存”“保存表单数据”。
7. 核对目标模板的 grid/report/table/subform 等布局、中文标题、默认值、选项、隐藏/禁用权限和必填校验；页面必须使用真实 `fm-generate-form`，不能把字段改成 Naive UI 输入框。缺少独立宿主适配的自定义组件或业务提交钩子应明确 `unsupported` 并阻止错误完成，不能降级成普通控件。
8. 对新发起点击“智能生成”。结果应综合模板默认值/选项、当前账号、当前路径条件和有限近期样本，显示自动填充与仍需手工数量；同一 seed 可复现。样本不足时有明确来源摘要并使用确定性兜底，复杂未知组件不编造值。
9. 手工修改一个生成字段后点击“换一组”，该人工值必须保留，其他生成器拥有字段才变化；“恢复已保存”回到当前路径最近一次保存。保存前必须触发真实 FormMaking 必填校验，保存的是 `getValues()` 完整对象和虚拟/系统辅助字段，而不是只保存屏幕基础字段。
10. 保存成功后刷新并重新打开，完整值、seed、生成字段和人工覆盖字段保持；表单完成但节点未全完成时路径仍是部分完成。另一条路径的数据、状态和会话不得串入当前路径。
11. 已发/待发表单默认显示所选真实实例当前值且只读；不得把工具侧数据写回目标实例，也不得调用目标提交流程、草稿或业务写接口。若模板包含上传、文件关联或业务保存按钮，点击后应显示受限/不支持反馈且 Network 中没有目标写请求；`find/list/get/query` 等已证明查询仍可正常加载并带当前会话 SID。
12. 切换计划、路径、账号或关闭表单工作区后再打开，确认旧会话响应不污染新页面；SID 不出现在 URL、浏览器长期存储、配置响应或维护日志中。深浅主题和较大模板的 iframe 高度/滚动保持可用。

## 表单运行时维护

13. 从“系统设置 → 表单运行时维护”进入维护页。固定来源必须显示 `rsh-flow-components`、`master`、本次可创建任务的当前 HEAD、dirty 和检查时间；页面只有“一键同步并更新运行时”，没有路径、分支、HEAD 或命令输入。
14. 来源干净时创建任务，观察阶段依次为 `INSPECT / SYNC / SYNC_CHECK / BUILD / RESTART / VERIFY / COMPLETED`，在线日志可刷新且过长时提示截断。重复点击或另开页面不能创建第二个活动任务。
15. 先完成 `make refs-sync` 后，新的干净 `master` HEAD 应能创建新任务；任务创建后再改变来源 HEAD 或弄脏来源，Worker 必须拒绝。候选代表性源码变化应进入真实表单服务；候选构建失败时 current 继续可用，19001 或生产 `/form-runtime/` 未报告新 HEAD/摘要时显示 previous 回退结果，恢复后再次打开表单工作区仍可使用。
