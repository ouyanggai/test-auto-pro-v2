# F-007 已保存路径的节点可视化配置人工验收

## 前置

- 启动前端和后端，准备一个已验证账号。
- 至少准备一条没有已保存路径的待配置计划，以及一条已有两条不同路径的待配置计划；最好包含条件/手动分支、并行、审批或协同节点。
- 如需验证可选处理人，目标模板必须真实返回该节点的合法候选；没有候选时应按运行时规则只读显示。

## 自动验证证据

- 已完整执行 `./test/run-f007.sh`，F-007 后端单元、API 契约、目标适配器集成、前端逻辑与结构检查，以及必要 F-004/F-005/F-006 回归、Go build、`vue-tsc`、Vite production build、`git diff --check` 全部通过。
- 本机未配置 `PLAN_DB_*`，MySQL 集成测试按脚本约定跳过；本轮未自动启动浏览器。

## 人工操作

1. 从 `/plans` 打开没有已保存路径的待配置计划。普通详情页“路径准备 / 下一步”应显示“请先配置并保存执行路径”和“配置路径”，不能显示“配置节点”。
2. 点击“配置路径”，确认仍进入原 F-005 页面全屏线路选择；新增、路径命名、条件/手动分支选择、并行必经、保存、编辑、复制、删除和退出全屏行为与已验收版本一致。保存一条路径后回到计划详情。
3. 在已有路径的计划详情中，确认每条路径显示稳定序号、名称、已配置/未配置状态和“配置节点”；“编辑路径”仍只改变线路，“配置节点”不进入线路选择。
4. 点击一条路径的“配置节点”，确认进入 `/plans/{planId}/paths/{pathId}/configure`。页面主体必须是流程画布：当前路径高亮，其他流程上下文弱化只读，节点显示“无需配置、待配置、部分完成、已完成、运行时确定、配置失效”等当前状态。
5. 确认顶部显示当前计划、路径稳定序号/名称、节点配置总数/已完成/待处理，并在存在待处理节点时提供“下一待配置节点”。点击该按钮只保持当前缩放并平移定位，不适配整图。
6. 依次点击发起、审批/协同、条件、手动分支、并行/汇聚和结束节点。固定右侧面板应只切换当前节点内容，画布不跳页、不重置视口；结构节点没有业务配置时只显示模板说明或无需配置，不伪造输入项。
7. 检查发起节点固定提交；审批/协同节点只显示真实允许的同意/不同意及线路影响说明。条件和手动分支展示已保存线路及中文模板要求；修改线路仍需返回“编辑路径”。
8. 检查基础字段只出现文本、数字、日期、日期时间、单选、多选和开关控件；中文字段名、必填和目标真实选项可读。未知控件、附件、明细表、业务对象、派生字段或权限不明项必须显示“暂不支持”原因，不得降级为普通文本框。
9. 检查人员规则：固定人员、角色、组织范围保持只读；目标实际返回合法候选且模板允许选择时才出现人员选择器，并遵守单选/多选和最低人数；依赖实际任务或目标没有返回候选时显示“运行时确定”，不能出现伪造的全员列表。对允许跳过且至少需要 2 人的会签节点，零人应允许作为跳过状态，选择 1 人时应按人员标题提示未满足模板要求且不能保存，选择 2 人后才恢复可保存；必选节点零人仍必须拒绝。
10. 对首次没有本地配置记录的路径，标题应显示“待保存配置”；即使默认值或实例现值未修改，只要必填项完整，“保存节点配置”也可用。保存成功后保留当前画布和节点结果，状态改为已保存，并显示“返回计划详情”；还有未配置路径时同时显示“配置下一条”，但不自动跳转。
11. 刷新当前配置页，确认已保存字段、人员和动作恢复在同一路径节点。打开另一条路径，确认高亮、节点状态和配置内容互不串联；返回计划详情后配置计数应更新。
12. 模拟或等待目标字段权限、选项或节点配置发生变化后重试保存，确认仅对应项标为受影响，仍可对应的草稿和当前节点保留；读取最新结构失败时也不能清空现场或显示内部 ID。
13. 切换深浅主题，拖动/缩放较大流程并使用页面全屏，确认节点、正交边、右侧面板和滚动清楚可用；开启系统减少动态效果后无多余动画。页面中不得出现暂停、继续、单步、断点、开始运行或目标平台写操作。

## 验收清单

- [ ] 无路径先“配置路径”，有路径才逐条显示“配置节点”；编辑线路与配置节点职责清楚。
- [ ] 配置页复用同一真实流程树和已保存路径，没有整页字段列表或第二套布局。
- [ ] 当前路径、路径外上下文、节点配置状态、下一待配置节点和固定右侧面板清晰。
- [ ] 发起、审批/协同、条件、手动分支、并行/汇聚/空/结束按类型展示，不伪造统一动作。
- [ ] 字段受目标控件、权限、必填和选项约束；未知或复杂组件显示明确缺口。
- [ ] 人员只有模板允许且目标返回合法候选时可选；可跳过会签零人合法、非零满足最低人数，固定、组织、角色和运行时规则不被伪造成候选。
- [ ] 首次保存、刷新恢复、保存失败保留、目标结构变化和两条路径隔离符合预期。
- [ ] F-005 路径新增、编辑、复制、删除、分支选择和页面全屏无回退。
- [ ] 深浅主题、缩放拖动、右侧独立滚动、长名称和减少动态效果正常。
- [ ] 计划仍为“待配置”，没有真实运行、单步、断点或目标平台写操作。
