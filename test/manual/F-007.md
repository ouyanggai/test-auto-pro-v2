## 人工操作路径

1. 从 `/plans` 打开一条待配置计划详情，不进入页面全屏。第一屏应完整显示返回、计划标题与状态、计划摘要和“路径准备 / 下一步”，底部不能露出半截流程画布。
2. 分别切换浅色、深色主题，确认路径准备卡片与页面/计划信息使用中性表面和主题边线；不得出现整块高饱和绿色。绿色只出现在主按钮或小型“已完成”状态，橙色只出现在“未配置”标签。
3. 无已保存路径时确认显示“下一步：新增执行路径”和主按钮“新增路径”；点击后才进入页面全屏线路选择。
4. 有已保存路径时确认普通页面直接显示“已保存 N 条，已配置 N 条，待配置 M 条”、每条稳定序号/名称/未配置或已配置标签和“配置”按钮；路径较多时只滚动卡片内列表，第一屏高度不变。
5. 在第一屏底部点击“查看流程结构”，正常动态设置下应平滑滚到第二屏顶部；开启系统减少动态效果后再次进入，点击应立即定位。滚轮向上、向下时两屏自然吸附，不回弹或连续抢滚动。
6. 第二屏顶部完整显示流程标题和说明，流程画布占用其余高度；右上角并列显示文字按钮“编辑路径”“页面全屏”。点击“页面全屏”只放大当前流程图，不自动打开路径管理；点击“编辑路径”才进入线路管理。
7. 路径准备区域存在待配置路径时点击“配置下一条”，确认直接打开第一条待配置路径；全部已配置时显示“路径配置已完成”，不显示“可运行”。
8. 点击某条“配置”进入 `/plans/{planId}/paths/{pathId}/configure`，检查中文字段、必填和目标选项；日期字段使用日期控件，日期时间字段使用日期时间控件，不能输入任意文本伪装日期。
9. 首次无配置记录时确认标题状态为“待保存配置”、底部不是“配置已保存”；即使默认值/实例现值不修改，只要必填完整，“保存配置”可用。保存成功后状态变为“已保存配置”。
10. 保存成功后确认当前配置结果仍保留且只显示一次“路径配置已保存”；页面提供“返回计划详情”，若仍有待配置路径提供“配置下一条”，不自动跳转。点击返回后普通详情的已配置/待配置数量立即更新。

## 检查项

- [ ] 从普通计划详情“路径准备 / 下一步”区域进入“配置”，没有独立的“路径要求核对”页面。
- [ ] 第一屏和第二屏各占完整内容视口，滚动时自然吸附；首屏不露出流程画布，流程屏顶部对齐且画布使用剩余高度。
- [ ] 路径准备卡片在深浅主题下均为中性表面；多路径列表只在卡片内部滚动，“查看流程结构”在正常/减少动态效果下分别平滑/立即定位。
- [ ] 普通流程图右上角同时看见文字“编辑路径”和“页面全屏”；前者进入线路管理，后者只放大查看，不自动打开路径管理。
- [ ] 当前路径的字段分组、节点顺序、中文字段名和基础控件清楚可读，内容区可以独立滚动。
- [ ] 字段选项来自目标平台；未知控件、人员、业务对象、附件、明细表和派生字段显示具体待补充原因且不可误填。
- [ ] 新发起显示当前模板默认值；已发/待发显示所选实例当前值，未编辑字段不会被空数据覆盖；已保存值存在时刷新仍优先显示已保存值。
- [ ] 发起节点显示提交；审批/协同节点默认推荐同意，选择不同意时有明确的线路影响提示。
- [ ] 修改并保存一条路径后刷新，值和动作仍保留；切换另一条路径没有串数据。
- [ ] 保存失败或目标结构变化时，草稿保留且错误定位明确；可继续修正后重试。
- [ ] 首次无配置显示待保存状态，保存成功才显示已保存状态；计划仍是“待配置”，没有目标平台提交、审批或开始运行按钮。
- [ ] 深浅主题、返回确认和长内容滚动正常。
