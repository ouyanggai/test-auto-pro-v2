# F-007 路径数据与节点动作配置人工验收

## 前置

- 已启动前端 `pnpm dev:f` 和后端 `pnpm dev:b`。
- 使用一个已验证账号和至少一条已经保存的执行路径。

## 检查项

- [ ] 从已保存路径详情进入“配置路径”，没有独立的“路径要求核对”页面。
- [ ] 当前路径的字段分组、节点顺序、中文字段名和基础控件清楚可读，内容区可以独立滚动。
- [ ] 字段选项来自目标平台；未知控件、人员、业务对象、附件、明细表和派生字段显示具体待补充原因且不可误填。
- [ ] 新发起显示当前模板默认值；已发/待发显示所选实例当前值，未编辑字段不会被空数据覆盖。
- [ ] 发起节点显示提交；审批/协同节点默认推荐同意，选择不同意时有明确的线路影响提示。
- [ ] 修改并保存一条路径后刷新，值和动作仍保留；切换另一条路径没有串数据。
- [ ] 保存失败或目标结构变化时，草稿保留且错误定位明确；可继续修正后重试。
- [ ] 计划仍是“待配置”，没有目标平台提交、审批或开始运行按钮。
- [ ] 深浅主题、返回确认和长内容滚动正常。
