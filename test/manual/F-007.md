## 人工操作路径

1. 从 `/plans` 打开一条待配置计划详情，不进入页面全屏，先在计划摘要下找到“路径准备 / 下一步”。
2. 无已保存路径时确认显示“下一步：新增执行路径”和主按钮“新增路径”；点击后才进入页面全屏线路选择。
3. 有已保存路径时确认普通页面直接显示“已保存 N 条，已配置 N 条，待配置 M 条”、每条稳定序号/名称/未配置或已配置标签和“配置”按钮；点击某条“配置”直接进入 `/plans/{planId}/paths/{pathId}/configure`，不需要先全屏。
4. 路径准备区域存在待配置路径时点击“配置下一条”，确认直接打开第一条待配置路径；全部已配置时显示“路径配置已完成”，不显示“可运行”。
5. 在普通流程图右上角确认并列显示文字按钮“编辑路径”“页面全屏”。点击“页面全屏”只放大当前流程图，不自动打开路径管理；退出后仍可看到路径准备区域。点击“编辑路径”才进入线路管理：已有路径显示已保存路径入口，无路径直接进入新增线路选择。全屏顶部继续显示文字“已保存的路径”“新增路径”“退出全屏”。
6. 在配置页检查中文字段、必填和目标选项；日期字段使用日期控件，日期时间字段使用日期时间控件，不能输入任意文本伪装日期。
7. 首次无配置记录时确认标题状态为“待保存配置”、底部不是“配置已保存”；即使默认值/实例现值不修改，只要必填完整，“保存配置”可用。保存成功后状态变为“已保存配置”。
8. 保存成功后确认当前配置结果仍保留且只显示一次“路径配置已保存”；页面提供“返回计划详情”，若仍有待配置路径提供“配置下一条”，不自动跳转。点击返回后普通详情的已配置/待配置数量立即更新。

## 检查项

- [ ] 从普通计划详情“路径准备 / 下一步”区域进入“配置”，没有独立的“路径要求核对”页面。
- [ ] 普通流程图右上角同时看见文字“编辑路径”和“页面全屏”；前者进入线路管理，后者只放大查看，不自动打开路径管理。
- [ ] 当前路径的字段分组、节点顺序、中文字段名和基础控件清楚可读，内容区可以独立滚动。
- [ ] 字段选项来自目标平台；未知控件、人员、业务对象、附件、明细表和派生字段显示具体待补充原因且不可误填。
- [ ] 新发起显示当前模板默认值；已发/待发显示所选实例当前值，未编辑字段不会被空数据覆盖；已保存值存在时刷新仍优先显示已保存值。
- [ ] 发起节点显示提交；审批/协同节点默认推荐同意，选择不同意时有明确的线路影响提示。
- [ ] 修改并保存一条路径后刷新，值和动作仍保留；切换另一条路径没有串数据。
- [ ] 保存失败或目标结构变化时，草稿保留且错误定位明确；可继续修正后重试。
- [ ] 首次无配置显示待保存状态，保存成功才显示已保存状态；计划仍是“待配置”，没有目标平台提交、审批或开始运行按钮。
- [ ] 深浅主题、返回确认和长内容滚动正常。
