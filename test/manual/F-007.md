# F-007 路径、人员与表单运行时人工核对

## 前置

- 启动主前端、复制的 `form-runtime` 和后端，准备一个已验证的目标平台账号。
- 准备一条新发起流程，以及可选的已发/待办历史实例。

## 路径与节点

1. 在计划详情中确认无路径时只能新增并保存执行路径；有路径后才显示“配置节点”。
2. 打开单条路径配置页，确认同一流程画布只允许当前路径节点切换，路径外节点不可编辑、拖拽或连线。
3. 在发起、审批、协同、分支、并行、汇聚、空和结束节点间切换，确认人员候选、动作目录和禁用原因来自目标读取结果。
4. 修改人员或独立动作记录后保存，确认服务端修订号对账成功；冲突时保留草稿，不产生半份配置。

## 原始表单工作区

1. 从节点配置页进入表单数据工作区，确认表单由复制的 `form-runtime` 渲染，主页面不显示字段映射器或模拟控件。
2. 分别打开 FormMaking 与目标 `vue_custom`/NoFormFlow 历史实例，确认目标返回的完整原始值可回显、编辑、校验和捕获。
3. 已发/待办实例只读；目标未注册组件显示阻塞问题，不能伪装为已支持。
4. 保存前执行 runtime 校验，保存后刷新并恢复同一份原始值；关闭工作区后迟到响应不得污染新路径或账号。
5. Network 只出现测试工具配置写入和目标只读请求，不出现目标流程提交、草稿、业务保存、上传或文件关联请求。

## 维护与边界

- 历史来源、路径状态和动作编译结果可重读；缺失数据或路径无法复验时显示 `needs_input`。
- 不执行真实流程，不创建运行记录，不使用生成器、随机造数、旧规则目录或路径准备任务。
