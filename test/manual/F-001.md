# F-001 手工验收

1. 在根目录执行 `pnpm dev:f`，打开 `http://127.0.0.1:19000/plans`。
2. 核对页面标题、九个表格字段、四种计划状态以及每行唯一主要操作；页面没有大卡片、灰色内容底、渐变或阴影。
3. 输入计划名称并选择状态，核对组合筛选真实改变表格行；清空后恢复全部 mock 行，无匹配项时显示正常空状态。
4. 依次点击“继续配置、开始运行、查看运行、查看结果”，确认只显示静态原型提示，不发生业务跳转或伪造后端结果。
5. 点击右上角“新建计划”，确认进入 `/plans/new` 独立整页；“返回测试计划”可回到列表。
6. 确认表单在内容区居中；“返回测试计划”处于普通文档流，向下滚动时不吸顶、不弹动，页面没有卡片堆叠、渐变或重阴影。
7. 空账号点击“验证账号”或提交，确认真实账号字段就地报错；输入任意非空账号后，按钮响应迅速并明确显示“本地静态验证、未登录真实平台”。
8. 未验证账号时确认“新发起”可选，“已发”“待发”不可选；验证后确认三个来源均可用。
9. 核对三个来源分别显示“流程模板”“已发流程”“待发流程”，页面不再出现“唯一流程来源”或统一“目标流程”输入框。
10. 核对运行方式/定时启动与流程选择区之间有清晰、克制的分隔线和留白，流程选择区不会与“定时启动”粘连。
11. 分别在三类列表中输入关键词、清空搜索、点击整行并滚动到底，核对空状态、清晰选中态、分批追加、加载和到底提示；三类列表与未验证空态切换时外壳高度保持稳定、仅有轻微过渡。
12. 切换来源时确认原来源选择被清空；编辑已验证账号时确认验证立即失效、来源回到“新发起”、选择被清空，旧批次不会重新出现。
13. 打开“定时启动”才显示启动时间，关闭后时间被清空；切换串行与并行，确认并行时才显示 2 至 20 的并发字段。
14. 验证账号成功或切换来源后，仅当搜索区未完整可见时才出现最小距离平滑引导并便于继续搜索；选中候选后按未完成项引导到启动时间、无效并发数或提交按钮。系统“减少动态效果”开启时，确认没有淡入位移或平滑滚动。
15. 未验证账号或未选择当前来源对象时提交应失败；填写完整后只短暂提示“静态原型已完成校验，真实创建将在后续功能接入”，不保存、不加入列表、不跳转路径页。
16. 在浅色与深色主题下核对表格、虚拟列表、分隔线和选中态；收缩侧栏后操作仍可用。
17. 在常见 1366×768 窗口下确认 body 不滚动；主内容区按需纵向滚动，虚拟列表在固定高度内独立滚动。

完成上述核对后，由用户明确决定是否把 F-001 从 `ready_for_manual` 推进到 `accepted`。未明确验收前不得开始 F-002。
