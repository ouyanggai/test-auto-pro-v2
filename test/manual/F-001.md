# F-001 手工验收

1. 在根目录执行 `pnpm dev:f`，打开 `http://127.0.0.1:19000/plans`。
2. 核对页面标题、九个表格字段、四种计划状态以及每行唯一主要操作；页面没有大卡片、灰色内容底、渐变或阴影。
3. 输入计划名称并选择状态，核对组合筛选真实改变表格行；清空后恢复全部 mock 行，无匹配项时显示正常空状态。
4. 依次点击“继续配置、开始运行、查看运行、查看结果”，确认只显示静态原型提示，不发生业务跳转或伪造后端结果。
5. 点击右上角“新建计划”，确认进入 `/plans/new` 独立整页；“返回测试计划”可回到列表。
6. 核对计划名称、真实账号、唯一流程来源、目标流程、运行方式和可选定时时间；切换账号或来源后，已经选择的目标流程被清空。
7. 切换串行与并行，确认并行时才出现“并行最大并发数”；分别验证必填项、2 至 20 边界和完整表单。
8. 点击“创建并选择路径”，确认校验成功后只提示“静态原型已完成校验，真实创建将在后续功能接入”，不保存、不加入列表、不跳转路径页。
9. 在浅色与深色主题下核对表格、表单、分隔线和菜单选中态；收缩侧栏后操作仍可用。
10. 在常见 1366×768 窗口下确认 body 不滚动；内容区按需纵向滚动，宽表格只在内容区内部水平滚动。

完成上述核对后，由用户明确决定是否把 F-001 从 `ready_for_manual` 推进到 `accepted`。未明确验收前不得开始 F-002。
