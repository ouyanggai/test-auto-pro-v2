# F-005 人工验收清单

## 启动

在两个终端分别运行：

```bash
pnpm dev:b
```

```bash
pnpm dev:f
```

打开测试计划列表，选择待配置计划的“继续配置”。本轮不需要额外填写环境变量，不会自动启动浏览器。

## 新发起计划

1. 打开一个直线流程计划，确认普通页面没有可点击分支；点击“线路选择”后自动进入页面全屏并出现右侧面板。未保存草稿显示“待分配序号”且不预占编号，无需选择分支即可保存；保存后默认名称使用事务实际分配的“路径 N”。自定义名称后保存并刷新，名称保持且稳定序号仍单独可见。
2. 打开包含条件、手动和并行的流程；确认单独点击“页面全屏”仍只能浏览。点击“线路选择”后，条件/手动分支标签至少 32px 高，可用鼠标、Tab 与 Enter/Space 改选，同一路由只高亮一支。
3. 确认并行各支显示“并行必经”且不能取消；嵌套路由剩余待选数准确。并行同时有多个待选路由时，面板只突出一个“下一待选点”，其他显示“后续待选”；未完成时“保存路径”不可用。
4. 保存两条不同线路并复制一条；确认相同线路允许作为独立路径保存，序号依次增加。
5. 删除当前最高序号路径后再新增；确认新序号继续增加，不复用、不重排其他路径。
6. 编辑已保存路径并改选同一路由另一支；保存后原路径序号不变，刷新和后端重启后选择仍恢复。
7. 先建立一个未保存草稿并输入自定义名称，再点击“一键生成全部路径”；确认弹窗先显示总组合、已存在和待新增数量，生成期间按钮显示忙碌且不能重复提交，完成后列表与数量刷新但当前草稿和名称原样保留。全部合法组合都有独立稳定序号与默认名称，再次点击时明确提示全部已存在且不会重复创建。超过 128 条的流程明确拒绝且不产生部分路径。
8. 将路径名称输入到 50 个字符，确认路径切换按钮不撑开 320px 面板，稳定序号始终可见，名称省略且悬停可查看全文。

## 已发与待发计划

1. 已发计划只从当前活动节点继续；`run` 和有可映射入口的 `await_sent` 可配置，已结束、终止、丢弃、驳回、撤回实例提示当前不能配置。
2. 待发计划从该实例全部 `waiting_send` 节点继续，并行活动入口不能被拆成多条路径。
3. 已发或待发保存一条后不再显示新增或复制入口；删除后允许重新选择一条。

## 画布与失败边界

1. 确认画布右上角“线路选择”紧邻“页面全屏”；普通页面和单纯页面全屏没有分支按钮。进入线路选择后右侧出现约 320px 面板，可收起，实时流向区域独立滚动，主图没有横跨画布的旧工具条。
2. 选择一条分支后，确认已选线路和并行必经线路使用明显主色、粗线与方向流动；实时流向摘要也同步显示方向动画。已选分支自身不可重复点击，同路由其他候选可点击和键盘改选。尚未到达子树的条件、手动与并行标签静止弱化、显示“尚未到达”且不可点击。开启系统“减少动态效果”后全部停止动画，状态仍可辨认。
3. 进入选择态以及每次选择后，确认下一待选点按左到右顺序提示并平滑移动到扣除右侧面板后的操作区域中央，缩放不变且不执行 `fitView`。气泡有明确箭头指向目标、可关闭并显示剩余数量，完整后只提示保存、不自动保存。
4. 点击“退出选择”后保持页面全屏浏览，再点“继续选择”确认草稿仍在；按 Esc 或点击“退出全屏”后再次进入，同样保留活动路径、未保存选择和当前观察位置。
5. 保存前让实例推进或流程结构变化；确认返回“流程已变化，需要重新选择”，最新图中仍能对应的选择保留，失效选择被移除并继续定位下一处，不按名称猜测。
6. 在最新图刷新阶段暂停后端或模拟目标读取失败；确认原草稿、模式和活动路径仍在，面板显示稳定错误和“重新读取”，不能用旧图直接误保存。
7. 让首次创建实际成功但客户端重试同一请求键，同时使目标读取暂时失败；确认仍返回同一路径与序号，不新增记录，也不显示目标读取错误。
8. 让批量生成实际成功但客户端丢失响应，再使用同一请求键重试并临时使目标读取失败；确认返回同一批次结果，不重复创建，也不重新依赖目标图。
9. 确认页面和日志不出现 SID、密码、AES key、目标原始响应、`create_key` 或内部 `next_path_sequence_no`。
10. 分别切换浅色和深色主题，确认右下角放大、缩小和全图三个按钮的背景、边框、图标、悬停及禁用状态都清楚可见。

## 范围边界

- 本轮计划状态仍为“待配置”，不提供表单值、人员、节点动作、运行、调度或报告。
- 除用户明确触发且不超过 128 条的完整路径组合外，不保存派生节点集合、流程图快照、版本或指纹，不调用目标写接口。
