# F-005 人工验收清单

## 启动

在两个终端分别运行：

```bash
pnpm dev:b
```

```bash
pnpm dev:f
```

打开测试计划列表，选择待配置计划的“继续配置”。本轮不需要额外填写环境变量，不会自动启动浏览器。

## 新发起计划

1. 打开一个直线流程计划，点击“新增路径”；确认无需选择分支即可保存，刷新后仍显示“路径 1”，列表和详情路径数量为 1。
2. 打开包含条件、手动和并行的流程；确认条件/手动分支标签至少 32px 高，可用鼠标、Tab 与 Enter/Space 改选，同一路由只高亮一支。
3. 确认并行各支显示“并行必经”且不能取消；嵌套路由剩余待选数准确，未完成时“保存路径”不可用。
4. 保存两条不同线路并复制一条；确认相同线路允许作为独立路径保存，序号依次增加。
5. 删除当前最高序号路径后再新增；确认新序号继续增加，不复用、不重排其他路径。
6. 编辑已保存路径并改选同一路由另一支；保存后原路径序号不变，刷新和后端重启后选择仍恢复。

## 已发与待发计划

1. 已发计划只从当前活动节点继续；`run` 和有可映射入口的 `await_sent` 可配置，已结束、终止、丢弃、驳回、撤回实例提示当前不能配置。
2. 待发计划从该实例全部 `waiting_send` 节点继续，并行活动入口不能被拆成多条路径。
3. 已发或待发保存一条后不再显示新增或复制入口；删除后允许重新选择一条。

## 画布与失败边界

1. 普通页面和页面全屏中拖动、缩放、选择分支；确认路径工具栏、全屏退出、Esc、深浅主题和右下角适配控件正常，选择不会触发自动 fitView。
2. 下一待选路由不在视口时，确认画布只做最小距离平移，缩放不变；已在视口内时不移动。
3. 保存前让实例推进或流程结构变化；确认旧选择被拒绝或标记需重新选择，仍能对应的选择保留，不按名称猜测。
4. 暂停后端或模拟目标读取失败；确认保存失败后草稿和当前视口保留，可直接重试，不回退 mock。
5. 确认页面和日志不出现 SID、密码、AES key、目标原始响应、`create_key` 或内部 `next_path_sequence_no`。

## 范围边界

- 本轮计划状态仍为“待配置”，不提供表单值、人员、节点动作、运行、调度或报告。
- 不生成、枚举或保存派生节点集合、流程图快照、版本或指纹，不调用目标写接口。
