# 审查功能切片

## 确定基线

1. 读取 `AGENTS.md`、当前功能文档及其产品、架构依据。
2. 确认审查起点和变更范围，忽略无关历史文件。
3. 把功能文档中的完成标准作为逐项核对表。

## 审查重点

1. 检查行为是否符合批准范围，是否提前实现后续功能。
2. 检查安全、进程生命周期、错误处理和数据覆盖风险。
3. 检查测试是否保存在根目录 `test/`、是否真的运行并覆盖关键失败路径。
4. 检查文档职责、状态流转、参考代码边界和中文提交记录。
5. 检查凭证、缓存、依赖、构建产物、运行文件和参考源码没有进入提交。

## 输出与门禁

- 先按严重程度报告可操作问题，并给出具体文件与位置。
- 没有问题时明确说明，并列出仍需用户手工验证的内容。
- 自动证据齐全时最多确认 `ready_for_manual`；只有用户明确验收才能是 `accepted`。
- 不自动修改实现，不自动开始下一功能。
