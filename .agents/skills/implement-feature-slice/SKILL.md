# 实施功能切片

## 开始条件

1. 读取 `AGENTS.md`、`CONTEXT.md`、当前功能文档及直接关联文档。
2. 确认功能已经获得用户批准且状态为 `implementing`。
3. 在写代码前列出本轮完成标准。

## 实施循环

1. 一次完成一个可独立验证的原子成果。
2. 只修改当前范围；发现旁支问题时记录，不顺手重构。
3. 将测试放到根目录 `test/` 对应分类，只运行当前相关测试。
4. 实际执行代码、测试、类型检查或构建，验证具体输出。
5. 检查暂存内容不含凭证、缓存、构建产物、运行文件或参考源码。
6. 验证通过后提交，提交说明必须使用中文。

## 完成与门禁

1. 执行功能文档中的全部自动完成标准。
2. 检查同一范围内是否存在相似问题。
3. 更新功能文档、路线图与进度，状态改为 `ready_for_manual`。
4. 给出用户可操作的手工核对步骤并停止。

不得把状态改为 `accepted`，不得自动开始下一功能。
