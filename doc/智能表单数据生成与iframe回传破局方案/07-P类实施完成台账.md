## 固定边界

- P 类没有修改目标系统，也没有发送目标提交、审批、草稿或业务保存请求。
- P4 不新增数据库表；预检快照只代表调用时的不可变值对象。未来真实运行必须持久化同形状快照，才能形成历史运行记录。
- P4 对浏览器只返回目标方法、路径、顶层键和 payload 摘要，不返回可直接发送的完整目标请求体。
- SID 按当前内网排障决定允许进入 URL、请求头、请求体、日志或后续持久化设计；P 类不再人为屏蔽，本轮也没有为 SID 新增数据库字段。
- 动态 FormMaking 提交钩子、缺少 Java 路由证据的 Vue 页面、stale 规则、候选失效和未确认配置都会明确 blocked。
