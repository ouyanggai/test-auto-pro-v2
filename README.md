# 流程自动化测试平台

面向目标流程平台的测试计划、路径选择与配置工具。它只在本项目自己的 MySQL 中保存测试计划和配置意图；配置阶段不会提交、暂存或修改目标平台流程。

## 当前状态

- F-007「路径数据与节点动作配置」已完成自动验证，当前状态为 `ready_for_manual`，仍等待人工复验。
- 后续真实执行、运行控制与结果回收尚未开始，不能视为已交付能力。

## 架构与边界

| 部分 | 开发端口 | 职责 |
| --- | --- | --- |
| Go 后端 | `127.0.0.1:19080` | 提供 `/api`、计划与路径配置持久化、目标平台只读适配及 MySQL 迁移。 |
| Vue 3 主前端 | `127.0.0.1:19000` | 提供计划、流程图、路径选择和节点配置界面；开发时将 `/api` 代理到 Go 后端。 |
| Vue 2 FormMaking form-runtime | `127.0.0.1:19001` | 独立表单渲染服务，嵌入配置页 iframe；与主前端通过版本化 `postMessage` 会话通信。 |

Form runtime 使用与目标平台同源的 FormMaking 组件逻辑渲染完整模板和虚拟字段。它的会话由当前已验证账号提供，目标读取与配置保存分别受运行时策略和后端 API 边界约束：不把 SID、目标凭证或目标原始响应写入仓库、浏览器长期存储或项目 MySQL；F-007 配置阶段不调用目标流程提交、草稿或业务写接口。

项目 MySQL 与目标平台数据存储隔离。目标平台仅通过现有 Go 适配器和表单运行时的受控只读链路访问；不要直连目标数据库，也不要修改 `参考代码/` 中的源码。

## 环境准备

- Go `1.25`
- Node.js `>=20.19`
- pnpm `10.25`（根目录已声明版本）
- 可连接的 MySQL：计划、路径和配置数据使用本项目独立数据库；后端启动会执行本项目迁移。
- 本机目标平台配置：参考 [.env.example](.env.example) 安全准备 Git 忽略的 `.env.local`，或通过同名进程环境变量覆盖。真实密码、SID、AES key、验收账号和网关地址不得提交。

安装前端依赖：

```bash
pnpm install
```

如需核对或维护只读参考代码，使用受控同步命令；正常启动不需要每次同步：

```bash
make refs-status
make refs-sync
make form-runtime-status
```

`make refs-sync` 只会按项目约束快进参考仓库。表单运行时同步属于维护操作，应先查看状态并确认参考代码工作树干净。

## 本地启动

在三个终端分别运行：

```bash
# 终端一：Go 后端（Air 热更新）
pnpm dev:b
```

```bash
# 终端二：Vue 3 主前端；dev:f 只启动主前端
pnpm dev:f
```

```bash
# 终端三：独立 Vue 2 FormMaking 表单运行时
pnpm dev:form
```

按各终端的 `Ctrl+C` 停止对应服务。常用地址：

- 主应用：[http://127.0.0.1:19000](http://127.0.0.1:19000)
- 后端健康检查：[http://127.0.0.1:19080/api/health](http://127.0.0.1:19080/api/health)
- 表单运行时开发入口：[http://127.0.0.1:19001/form-runtime/](http://127.0.0.1:19001/form-runtime/)

可用以下命令检查后端：

```bash
curl -fsS http://127.0.0.1:19080/api/health
```

## 使用边界

- 无已保存路径时，先在计划详情配置执行路径；有路径后再进入该路径的节点与表单配置。
- “页面全屏”只用于查看流程图；线路编辑与节点/表单配置是独立操作。
- F-007 即使显示为已完成自动验证，也必须经过人工复验后才能作为后续真实执行的输入。
- 遇到目标接口、模板或人员目录变化时，重新读取并复验；不要以旧配置替代当前目标结构。
