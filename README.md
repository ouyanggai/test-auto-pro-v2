## 项目组成

| 部分 | 地址 | 用途 |
| --- | --- | --- |
| Go 后端 | `http://127.0.0.1:19080` | API、计划与路径数据、目标平台读取。 |
| Vue 3 主前端 | `http://127.0.0.1:19000` | 日常操作界面。 |
| Vue 2 form-runtime | `http://127.0.0.1:19001` | 独立的 FormMaking 表单渲染服务。 |

## 运行环境

- Go `1.25`
- Node.js `>=20.19`
- pnpm `10.25`
- 可连接的 MySQL
- 项目根目录的 `.env.local`

`.env.local` 包含本机 MySQL 与目标平台配置，由项目负责人私下提供。拿到后直接放在项目根目录；它不得提交到 Git，也不要把密码、SID、验收账号或网关地址写入 README。

## 首次安装

```bash
pnpm install
```

## 最短启动步骤

确认根目录已有 `.env.local` 后，打开三个终端并依次执行：

```bash
# 终端一：后端
pnpm dev:b
```

```bash
# 终端二：主前端
pnpm dev:f
```

```bash
# 终端三：独立表单运行时
pnpm dev:form
```

随后访问 [主应用](http://127.0.0.1:19000)。后端健康检查为 [http://127.0.0.1:19080/api/health](http://127.0.0.1:19080/api/health)，表单运行时地址为 [http://127.0.0.1:19001/form-runtime/](http://127.0.0.1:19001/form-runtime/)。每个服务均可在自己的终端按 `Ctrl+C` 停止。

## 启动检查与常见问题

```bash
curl -fsS http://127.0.0.1:19080/api/health
```

- 端口被占用：停止占用 `19080`、`19000` 或 `19001` 的本机进程后重试。
- 缺少 `.env.local`：向项目负责人索取本机配置，不要自行提交或共享凭证。
- MySQL 不可用：确认 `.env.local` 的 `PLAN_DB_*` 配置和数据库服务可连接。
- 目标配置缺失：确认 `.env.local` 的 `TARGET_*` 配置有效；健康检查可以正常，但目标读取接口会拒绝请求。
