# 流程自动化测试平台

流程自动化测试平台帮助测试人员基于目标平台的真实账号和真实流程，准备不同执行路径所需的人员、动作与表单数据，并逐步形成可运行、可追溯的流程测试方案。

## 产品大纲

账号与流程选择 → 创建测试计划 → 查看真实流程结构 → 配置执行路径 → 配置节点人员、动作和表单数据 → 运行准备 → 真实执行 → 查看运行记录

当前版本已覆盖前半段的计划与配置工作；执行与结果查看仍在后续规划中。

## 项目组成

| 服务 | 地址 | 用途 |
| --- | --- | --- |
| Go 后端 | `http://127.0.0.1:19080` | 提供 API、计划与路径数据，并读取目标平台信息。 |
| Vue 3 主前端 | `http://127.0.0.1:19000` | 提供日常操作界面。 |
| Vue 2 form-runtime | `http://127.0.0.1:19001` | 独立渲染 FormMaking 表单。 |

## 运行环境

- Go `1.25`
- Node.js `>=20.19`
- pnpm `10.25`
- 可连接的 MySQL
- 项目根目录的 `.env.local`

`.env.local` 包含本机 MySQL 和目标平台配置，由项目负责人私下提供。拿到后直接放在项目根目录；不得提交到 Git，也不要共享其中的密码、SID、账号或网关地址。

## 首次安装

```bash
pnpm install
```

## 启动项目

确认项目根目录已有 `.env.local` 后，打开三个终端并依次执行：

```bash
# 终端一：后端
pnpm dev:b
```

```bash
# 终端二：主前端
pnpm dev:f
```

```bash
# 终端三：独立表单运行时
pnpm dev:form
```

启动后访问：[主应用](http://127.0.0.1:19000)。

- 后端：`http://127.0.0.1:19080`
- 主前端：`http://127.0.0.1:19000`
- 表单运行时：`http://127.0.0.1:19001/form-runtime/`

每个服务都可在自己的终端按 `Ctrl+C` 停止。

## 启动检查与常见问题

```bash
curl -fsS http://127.0.0.1:19080/api/health
```

- 端口被占用：停止占用 `19080`、`19000` 或 `19001` 的本机进程后重试。
- 缺少 `.env.local`：向项目负责人索取本机配置，不要自行提交或共享凭证。
- MySQL 不可用：确认 `.env.local` 中的 `PLAN_DB_*` 配置和数据库服务可连接。
- 目标配置缺失：确认 `.env.local` 中的 `TARGET_*` 配置有效；健康检查可以正常，但读取目标流程会失败。
